## 公司简介

度小满是一家专注于金融科技的创新型公司，致力于通过技术驱动，提升金融服务的效率与可达性。公司业务覆盖多个领域，已累计服务数千万用户，连接起广泛的金融生态合作伙伴，包括银行、保险、基金等机构。凭借强大的技术能力和严谨的风控体系，度小满已成长为国内领先的金融科技平台之一。

## 核心业务

### 主要产品

**产品1：有钱花/度小满信贷服务**
- 产品定位：为个人消费者及小微企业主提供智能、便捷、安心的互联网信贷服务
- 核心卖点：申请简便、审批快、额度高、放款快、安全性强、利率4.9%-14%
- 目标用户：小微企业主、个体工商户、青年创业者

**产品2：度小满金融科技输出**
- 产品定位：为银行等金融机构提供金融科技解决方案
- 核心卖点：智能营销、智能风控、智能经营与智能运营
- 目标用户：中国工商银行、中国农业银行等上百家银行和金融机构

### 业务数据

| 指标 | 数据 |
|------|------|
| 累计服务用户 | 数千万 |
| 服务覆盖 | 全国31个省区市 |
| 小微用户占比 | 7成是员工在5人以下的小店 |
| 低线城市占比 | 超过50%分布在四线及以下城市 |
| 核心竞争优势 | 利率4.9-14%，低于行业平均水平 |

## 公益项目

### 公益IP 1：小满助力计划
- **发起时间**：2019年提出，2020年5月21日启动亿元免息项目
- **项目性质**：信用贷款，无需抵押担保
- **支持对象**：乡村新型经营主体、脱贫户、普通农户、乡创青年、小微个体
- **支持手段**：免息贷款
- **数据**：
  - 累计放款：4.5亿元
  - 覆盖范围：全国31个省（区、市）的602个行政村
  - 受益农户：超过36万户间接受益
  - 支持产业：74个种植业、25个养殖业，以及乡村民宿、乡村电商等新兴产业
  - 女性用户占比：超8成

### 公益IP 2：青年小店榜样计划
- **发起时间**：2024年12月13日
- **合作伙伴**：中国青年创业就业基金会
- **支持对象**：青年小店主理人和返乡创业青年
- **支持手段**：免息贷款+技能培训+宣传推广
- **数据**：
  - 服务青年创业者：800余名
  - 提供免息贷款：1600万元
  - 落地城市：张家口、建德、长沙、佛山、丽水等7个城市

### 公益IP 3：乡村振兴领航员人才培养
- **发起时间**：2021年9月
- **合作伙伴**：友成基金会
- **支持对象**：乡村产业带头人
- **支持手段**：线上课程学习+进阶式创业赋能+陪伴式孵化
- **数据**：
  - 培养周期：6个月
  - 培养内容：产品打造和直播带货创业培训
  - 落地地区：贵州雷山、湖南安化、四川雅安、重庆黔江四地
  - 累计培养：超230位乡村产业带头人

### 公益IP 4：联合国开发计划署合作
- 签署"可持续金融助力乡村振兴"项目合作协议

## 行业舆论定位

### 企业优势认知
- 技术领先：轩辕大模型、AI风控技术得到行业认可
- 服务小微：服务数千万小微企业，助力普惠金融
- 企业责任：小满助力计划、青年小店榜样计划等公益项目
- 安全可靠：可信赖的金融科技伙伴形象

### 潜在风险点
- 网贷行业偏见：部分公众对网贷行业存在负面刻板印象
- 利率敏感：对利率、费用等问题较为敏感
- 信息安全：对个人信息保护、数据安全问题关注度高

### 行业竞品
- 蚂蚁集团：支付宝、蚂蚁财富、网商银行
- 腾讯金融科技：微信支付、理财通、微众银行
- 京东数科：京东支付、京东金融
- 字节跳动：抖音支付、头条财经
