# 中国舆论场媒体/自媒体知识图谱

> 整理时间：2026年4月 | 聚焦：互联网、金融、科技、民生社会

---

## 一、央媒党媒

- **人民日报** — 中共中央机关报。党政方针、政策定调、社论。"任仲平"评论品牌是最高级别政策风向标。旗下人民网是最大中文新闻门户之一。
- **新华社** — 国务院（国家通讯社）。重大事件首发通稿、内参、权威信息。"新华视点"调查品牌。所有重大新闻原则上以新华社为准。旗下中国经济信息社办"新华财经"。
- **中央广播电视总台（央视/央广/国广）** — 中宣部。视频传播力全国最强。"新闻联播""焦点访谈""315晚会"。新媒体端"央视新闻"客户端日活破千万。
- **环球时报** — 人民日报社。国际时评、中美博弈、民族主义叙事。胡锡进（前总编）个人IP延续极大影响力，微博/公众号"胡锡进"仍为舆论场关键节点。
- **光明日报** — 中宣部。思想理论、知识分子、教育科技文化。
- **经济日报** — 国务院。宏观经济政策、产业动态。中国经济网为其官网。
- **中国青年报** — 共青团中央。青年话题、教育就业。"冰点周刊"特稿是新闻写作标杆。
- **参考消息** — 新华社。编译国际新闻，"外国人看中国"视角。全国发行量最大日报之一。
- **中国日报** — 国务院新闻办。英文对外传播主力。
- **中国新闻社/中新社** — 中央统战部。面向海外华人的新闻供给。"国是直通车"公众号有影响力。
- **解放军报** — 中央军委。国防军事权威发布。
- **法治日报** — 司法部。法治新闻、法律监督。
- **工人日报** — 全国总工会。劳动权益、工会动态。
- **农民日报** — 农业农村部。三农政策、乡村振兴。
- **科技日报** — 科技部。科技政策、重大科技成果发布。
- **中国纪检监察报** — 中央纪委国家监委。反腐报道权威来源。

## 二、财经/商业媒体

### 2.1 市场化财经媒体

- **财新传媒** — 民营，创始人胡舒立。股东含华人文化（黎瑞刚）、腾讯、蚂蚁集团等。中国新闻专业主义旗帜，调查报道最强（安邦、明天系、赖小民等系列报道）。付费墙模式先行者。旗下《财新周刊》、财新网、Caixin英文。前身为《财经》杂志团队。
- **第一财经** — 上海文化广播影视集团（SMG）。股市行情、宏观经济、公司报道。电视频道+APP+网站全媒体。"CBNData"做消费数据研究。
- **21世纪经济报道** — 南方报业传媒集团。产业新闻、区域经济、金融。覆盖面广，产业记者团队庞大。
- **经济观察报** — 民营（山东三联集团背景）。"理性、建设性"定位，长篇深度公司报道，橙色报纸辨识度高。
- **每日经济新闻** — 成都传媒集团。资本市场报道速度快，上市公司舆情监控强。新媒体转型较好，"每经APP"流量大。
- **界面新闻/财联社** — 上海报业集团旗下（上海界面财联社科技股份有限公司）。财联社7×24小时金融快讯，定位"中国彭博/路透"；界面做深度商业报道。有新闻牌照，合并了原华尔街见闻部分团队。
- **中国经营报** — 中国社会科学院主管。产业经济、公司报道。"企业观察报"为其子报。
- **华夏时报** — 民营（水皮任总编辑）。资本市场、金融投资。
- **证券日报》** — 经济日报社主管。证监会指定信息披露媒体，上市公司报道。
- **上海证券报》** — 新华社主管。上交所指定信息披露媒体。
- **证券时报》** — 人民日报社主管。深交所指定信息披露媒体。
- **中国基金报》** — 证券时报主管。公募/私募基金领域最专业媒体。
- **期货日报》** — 郑州商品交易所主管。期货/衍生品领域。
- **国际金融报》** — 人民日报社主管。上海立场，金融领域。

### 2.2 财经门户/平台

- **新浪财经** — 新浪公司。综合财经门户，7×24小时滚动，流量最大之一。
- **东方财富网** — 民营上市公司。"股吧"社区是散户最大集散地，基金销售+数据服务。
- **雪球** — 民营（创始人方三文）。投资社区，UGC为主，KOL投资达人聚集。产品化能力强。
- **同花顺** — 民营上市公司。行情软件+财经资讯，C端用户量最大。
- **和讯网** — 民营。老牌财经门户，近年影响力下滑。
- **金融界** — 民营上市公司。财经数据+资讯。

### 2.3 财经自媒体

- **吴晓波频道** — 吴晓波（财经作家），杭州巴九灵公司运营。宏观经济、产业趋势、新中产。"每年写一本书"品牌；《激荡三十年》《大败局》等著作。知识付费+线下活动。粉丝400万+，新中产定位。
- **半佛仙人** — 金融行业出身，B站起家。互联网商业、消费陷阱、金融风控。"硬核+搞笑"风格，反黑产反诈骗揭露。公众号+视频双线，B站财经顶流。
- **远川研究所/饭桶戴老板** — 上海远川文化传播有限公司。产业深度研究（地产、新能源、半导体）。"戴老板"人设，机构化运营，产业报告+长文。
- **兽楼处** — 兽爷（地产/金融背景）。地产调查最强，《疫苗之王》引爆长生生物事件。不定期更新，篇篇重磅。
- **衣公子** — 金融、跨境资本、商战叙事。长篇商业故事，文笔流畅。
- **刘润** — 前微软战略顾问。商业方法论、管理咨询。"5分钟商学院"，企业培训+知识付费。
- **香帅的金融江湖** — 唐涯（原北大金融学教授）。金融科普、财富管理。"中国财富报告"系列，学术+通俗。
- **饭统戴老板** — 同远川研究所，早期个人号名，后品牌化。
- **智本社** — 清华背景团队。宏观经济、货币分析。偏学术。
- **冷眼看盛世** — 个人IP。宏观经济、房地产、社会结构分析。
- **政事堂2019** — 个人IP（顾子明）。政经分析，"庙堂"视角，政策解读快。争议性大但影响力强。
- **水印读书** — 个人IP。财经、历史、哲学交叉。
- **投中网** — 投中信息。创投领域，VC/PE行业报道，"投中榜"排名有行业影响力。
- **阿尔法工场** — 民营。金融从业者社区，投行/PE/二级市场。
- **市界** — 民营。上市公司商业故事，"读懂中国公司"。
- **开菠萝财经** — 民营。互联网消费、新经济公司。
- **深氪** — 36氪旗下深度团队。互联网公司深度报道。
- **商业人物** — 民营。商界人物特稿，"人物"风格。

## 三、科技/互联网媒体

### 3.1 科技新媒体

- **36氪** — 民营，纳斯达克上市（KRKR）。创投起家，科技创投媒体流量最大。投融资报道、创业公司动态、"9点早报"。旗下氪空间做联合办公，鲸准做创投数据。2020年后做付费会员"36氪会员"。
- **钛媒体** — 民营，创始人赵何娟。TMT产业、科技商业、一级市场。偏严肃风格，深度调查报道（对蚂蚁金服、36氪的批评报道）。"链得得"做区块链子品牌。新华社新媒体供稿源。
- **虎嗅** — 民营，创始人李岷（《中国企业家》杂志出身）。商业评论、互联网趋势、社会热点。**编辑选稿能力是核心竞争力**，培育了大量外部作者。观点犀利，关注面超越科技。
- **雷锋网** — 民营，创始人林军。早年关注移动互联网，后转向AI/芯片/自动驾驶/安全等硬科技。"AI掘金志"等子栏目。
- **极客公园** — 民营，创始人张鹏。互联网产品、科技趋势。社区+线下活动（奇点大会/Rebuild大会），产品观察和CEO对话。
- **爱范儿** — 民营。消费数码、App评测、科技生活方式。苹果生态报道见长。
- **IT之家** — 民营。IT资讯快讯、数码产品、软件。速度快，PC/手机技术资源丰富。偏极客用户。
- **差评** — 民营（腾讯投资）。消费数码评测、科技热点评论。年轻化、有态度，微信公众号起家。
- **硅星人** — 民营。硅谷科技、海外互联网、出海。品玩旗下。
- **36氪的朋友们** — 36氪旗下UGC平台，作者投稿。
- **钛度热评** — 钛媒体旗下评论栏目。

### 3.2 AI/前沿科技垂直

- **新智元** — 民营（创始人杨静）。AI产业、大模型、人工智能应用。AI垂直领域影响力最大之一。产业会议+内容。

- **机器之心** — 民营。AI技术论文解读、前沿研究。偏学术路线，论文解读质量最高。
- **Synced** — 机器之心英文版。
- **ChatGPT指南** — 民营。大模型应用、AI工具教程。
- **AIGC开放社区** — 民营。AIGC产业、大模型开源。
- **智东西** — 民营。AI/芯片/自动驾驶/智能硬件。产业报道+会议。
- **车东西** — 民营。智能汽车、自动驾驶、新能源车。智东西兄弟品牌。
- **半导体行业观察** — 民营。芯片/半导体产业最专业垂直号。

### 3.3 科技自媒体

- **晚点LatePost** — 前财经记者宋玮创办。互联网公司内幕、科技巨头动态。**互联网公司报道最权威自媒体之一**。独家/内幕信息多，深度长文，字节/阿里/腾讯等报道标杆。

- **甲子光年** — 民营（创始人张一甲）。科技产业调研、AI/新能源/半导体。产业报告+会议，2B影响力大。
- **刺猬公社** — 民营。内容产业、文娱、短视频行业观察。
- **字母榜** — 民营（马钺等，虎嗅系出身）。互联网大公司动态。
- **乱翻书** — 个人IP（赵依依）。互联网产品、组织管理、战略分析。
- **卫夕指北** — 个人IP。互联网广告、商业化、产品分析。
- **壹娱观察** — 民营。文娱产业、影视、游戏。
- **懂懂笔记** — 个人IP。互联网商业、科技产业。
- **银杏科技** — 民营。互联网公司、消费科技。

## 四、时政/社会/民生媒体

### 4.1 综合时政新媒体

- **澎湃新闻** — 上海报业集团（解放日报社旗下）。从《东方早报》转型。**中国最具影响力时政新媒体**。调查报道、政经新闻、社会热点。"澎湃号"开放平台。日活破千万。栏目细分：澎湃新闻、澎湃人物、澎湃思想、澎湃美育等。
- **观察者网** — 上海观察者信息技术有限公司+上海春秋发展战略研究院。创始人李世默（复旦大学中国研究院理事），总编辑金仲伟。**"中国关怀、全球视野"**。民族主义+产业升级叙事。张维为、金灿荣、陈平、沈逸等学者专栏。科技/军工领域报道突出。年轻男性用户为主。B站/视频号流量大。"风闻"社区。
- **南方周末** — 南方报业传媒集团。深度调查报道传统品牌，"在这里读懂中国"。近年调查力度有收敛，但仍是深度新闻标杆。
- **南方都市报** — 南方报业传媒集团。民生新闻、舆论监督。"南都"品牌，都市报转型。
- **新京报** — 北京市委宣传部主管（2021年由光明日报划转）。社会新闻、调查报道。"我们视频"短视频品牌影响力大。
- **上游新闻** — 重庆日报报业集团。社会调查、舆论监督。深度调查报道有全国影响。
- **极目新闻** — 楚天都市报（湖北日报传媒集团）。社会新闻、民生热点。新媒体转型较成功。
- **九派新闻** — 长江日报报业集团。社会新闻、短视频。B站/抖音分发。
- **正观新闻** — 郑州报业集团。社会新闻、民生。
- **红星新闻** — 成都传媒集团（成都商报）。调查报道、社会热点。近年崛起快。
- **大河报** — 河南日报报业集团。河南民生。
- **潇湘晨报** — 中南出版传媒集团。湖南民生。

- **冯站长之家** — 冯国亮（个人IP）。新榜民生类常年第一。"每天三分钟，知晓天下事"，人工精选新闻早餐。中老年用户为主。

- **丁香医生** — 杭州联科美讯（丁香园旗下）。中国最大健康科普自媒体。循证医学风格。曾因争议文章被限流。

## 十、重要提醒

1. **新闻牌照**：中国实行新闻采编资质管理，只有持证媒体（央媒、报业集团下属、持证商业媒体）有合法采编权。自媒体无采编权，只能评论/转载。
2. **宣传纪律**：所有媒体受各级宣传部业务指导，重大时政/敏感议题有统一口径。
3. **自媒体风险**：自媒体人设和商业利益捆绑紧密，需注意广告软文与独立观点的区分。大号"翻车"事件频发。
4. **信息验证**：同一事件建议交叉验证，特别是自媒体爆款文章，情绪传播优先于事实核查。
5. **动态变化**：媒体股权/人事/立场可能随时变化，本整理基于2026年4月时点公开信息。
