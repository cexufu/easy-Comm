## 一、模拟目标用户构建原则

### 1. 真实性原则
- 用户必须基于真实的目标群体特征构建
- 不应理想化或美化，要保留真实的偏见和局限

### 2. 典型性原则
- 选择该群体中最具代表性的用户类型
- 避免极端个例或边缘情况

### 3. 偏见保留原则
- 必须保留代际、产业、性别、国别、年龄等方面的偏见
- 这些偏见是评估时的关键参考因素

### 4. 内容偏好限定
- 用户只关注近期该类群体日常关注的内容
- 不应跨领域或跨兴趣内容消费

## 二、用户画像模板

### 基础信息
- **年龄**：具体年龄段（如：25-30岁）
- **性别**：男/女
- **职业**：具体职业类型（如：互联网产品经理、制造业工程师）
- **地域**：城市层级或具体地区（如：一线城市新一线城市、三四线城市）
- **收入**：收入区间（如：月入1-2万）
- **教育**：学历水平（如：本科、硕士）

### 内容消费习惯
- **主要平台**：日常使用的平台（如：抖音、B站、知乎、今日头条）
- **内容偏好**：偏好内容类型（如：科技数码、职场成长、生活记录）
- **消费时段**：内容消费高峰时段（如：通勤时间、睡前）
- **关注博主**：典型关注的博主类型（如：知识型博主、娱乐博主）

### 典型偏见
- **代际偏见**：如"95后都是眼高手低"、"70后不懂互联网"
- **产业偏见**：如"互联网行业就是收割用户"、"制造业就是低端"
- **性别偏见**：如"男性适合技术"、"女性适合人文"
- **国别偏见**：如"国外的东西就是好"、"国内只会抄袭"
- **年龄偏见**：如"年轻人吃不了苦"、"老年人思想陈旧"

### 近期关注焦点
- 列举3-5个该群体近期最关注的话题或事件

## 三、评估维度说明

### ⚠️ 网感专项评估（第9维度，最高优先级）

**决策规则**：
- 网感指数 < 4分：直接重写/拒绝，不允许进入后续评估
- 网感指数 ≥ 4分：才进入8维度评估流程

#### 小红书网感评估（S/A/B/C/D级）

**网感5维度评分**：

1. **原生感（25%）**：是否像真实用户分享，而非营销文案
   - 说真话、说大白话
   - 有个人口吻和风格
   - 不装、不端着
   - 像和闺蜜聊天

2. **即时感（20%）**：是否有"刚刚发生"的时效感
   - 用"今天""刚刚"等时间词
   - 有紧迫感和新鲜感
   - 有即时分享欲

3. **亲近感（20%）**：是否让用户感觉亲近
   - 用"你们""我们""姐妹们"
   - 有情感连接和共同经历
   - 有身份认同

4. **节奏感（20%）**：是否符合小红书阅读习惯
   - 短小精悍，段落短小
   - 有呼吸感，不拖沓
   - 一段话3-5行

5. **社交货币（15%）**：是否值得分享讨论
   - 有"收藏转发"价值
   - 有"身份标签"价值
   - 有"话题谈资"价值

**长度限制**：
- 超过500字：直接0分，必须重写
- 400-500字：扣30%
- 300-400字：正常
- 200-300字：加10%
- 200字以下：加20%

**网感等级**：
- S级（90-100分）：网感极佳，爆款潜力
- A级（80-89分）：网感优秀，有潜力
- B级（70-79分）：网感良好，需优化
- C级（60-69分）：网感一般，需改进
- D级（60分以下）：网感差，必须重写

---

#### 短视频网感评估（S/A/B/C/D级）

**网感5维度评分**：

1. **钩子强度（30%）**：前3秒是否能瞬间抓住注意力
   - 钩子是否有冲突性
   - 钩子是否有悬念性
   - 钩子是否有情绪性
   - 钩子是否有相关性

   **评分**：
   - 30分：超强钩子，用户一定会看下去
   - 24分：强钩子，大部分用户会看下去
   - 18分：中强钩子，一半用户会看下去
   - 12分：弱钩子，少数用户会看下去
   - 6分：无钩子，用户直接划走

2. **反差度（25%）**：是否有强烈反差和转折
   - 是否有预期反转
   - 是否有身份反转
   - 是否有结果反转
   - 是否有情绪反转

   **反差层数**：
   - 3层反差：25分（满分）
   - 2层反差：20分
   - 1层反差：15分
   - 0层反差：5分

3. **节奏感（20%）**：视频节奏是否紧凑
   - 节奏是否紧凑不拖沓
   - 信息密度是否适中
   - 画面切换是否流畅
   - 音乐卡点是否精准

   **评分**：
   - 20分：节奏完美，全程无尿点
   - 16分：节奏良好，少数拖沓
   - 12分：节奏一般，部分拖沓
   - 8分：节奏较差，多处拖沓
   - 4分：节奏很差，全程拖沓

4. **情绪强度（15%）**：是否能激发强烈情绪
   - 情绪是否到位
   - 情绪是否递进
   - 情绪是否有峰值
   - 情绪是否能共鸣

   **评分**：
   - 15分：情绪极强，强烈共鸣
   - 12分：情绪较强，明显共鸣
   - 9分：情绪一般，少量共鸣
   - 6分：情绪较弱，无明显共鸣
   - 3分：情绪极弱，无共鸣

5. **互动引导（10%）**：是否能有效引导互动
   - 互动引导是否自然
   - 互动引导是否具体
   - 互动引导是否有吸引力
   - 互动引导是否易执行

**时长限制**：
- 超过60秒：直接0分，必须重写
- 45-60秒：扣20%
- 30-45秒：正常
- 15-30秒：加15%
- 15秒以下：加10%

**前3秒检查**：
- 前3秒无钩子：直接0分，必须重写
- 第1秒无钩子：扣20分

**网感等级**：
- S级（90-100分）：网感极佳，爆款潜力
- A级（80-89分）：网感优秀，有潜力
- B级（70-79分）：网感良好，需优化
- C级（60-69分）：网感一般，需改进
- D级（60分以下）：网感差，必须重写

---

#### 新闻稿网感评估（S/A/B/C/D级）

**网感4维度评分**：

1. **新闻性（35%）**：是否具有新闻价值
   - 是否有新鲜性和时效性
   - 是否有重要性和影响力
   - 是否有接近性和相关性
   - 是否有异常性和冲突性

2. **真实性（25%）**：是否基于事实
   - 是否有确凿证据支撑
   - 是否有可靠消息来源
   - 是否有数据支持
   - 是否可验证

3. **客观性（20%）**：是否客观中立
   - 是否避免主观臆断
   - 是否平衡多方观点
   - 是否避免情绪化表达
   - 是否符合媒体伦理

4. **专业性（20%）**：是否专业权威
   - 语言是否专业准确
   - 结构是否清晰合理
   - 引用是否规范
   - 是否符合媒体标准

**时效要求**：
- 即时新闻：2小时内发布（满分）
- 当日新闻：当日内发布（正常）
- 深度报道：可延至1-3天（可接受）
- 无时效性：扣30%

**导语质量**：
- 导语不符合5W1H原则：扣20%
- 导语超过80字：扣10%
- 导语信息不全：扣15%

**网感等级**：
- S级（90-100分）：网感极佳，媒体录用潜力高
- A级（80-89分）：网感优秀，媒体录用潜力良好
- B级（70-79分）：网感良好，需优化
- C级（60-69分）：网感一般，需改进
- D级（60分以下）：网感差，必须重写

### 前8维度评估（网感≥4分后才执行）

### 1. 吸引力（1-5分）

**评分标准**：
- 5分：标题/开场极具吸引力，立即抓住注意力
- 4分：标题/开场有吸引力，能引起兴趣
- 3分：标题/开场一般，有一定吸引力
- 2分：标题/开场较弱，吸引力不足
- 1分：标题/开场无吸引力，不会注意

### 2. 点击停留时长（1-5分）
**定义**：预测用户在内容上的停留时间

**评分标准**：
- 5分：预计停留时间超过内容时长的90%（短视频）或读完全文（长文）
- 4分：预计停留时间超过内容时长的70%
- 3分：预计停留时间超过内容时长的50%
- 2分：预计停留时间低于内容时长的30%
- 1分：预计停留时间低于内容时长的10%

### 3. 完播率/全文阅读率（1-5分）
**定义**：预测用户是否会完整看完内容

**评分标准**：
- 5分：几乎肯定会看完（概率>90%）
- 4分：大概率会看完（概率70-90%）
- 3分：可能看完（概率50-70%）
- 2分：不太可能看完（概率30-50%）
- 1分：几乎不会看完（概率<30%）

### 4. 内容互动意愿（1-5分）
**定义**：用户是否愿意进行点赞、评论、转发等互动

**评分标准**：
- 5分：强烈意愿，会主动互动并分享
- 4分：有意愿，可能会点赞或评论
- 3分：意愿一般，可能只看不互动
- 2分：意愿较弱，不太可能互动
- 1分：无意愿，不会互动

### 5. 记忆点（1-5分）
**定义**：内容是否有令人印象深刻的记忆点

**评分标准**：
- 5分：有多个记忆点，印象深刻，会记住
- 4分：有1-2个记忆点，印象深刻
- 3分：有一定记忆点，但不够深刻
- 2分：记忆点模糊，看完可能忘记
- 1分：无记忆点，看完即忘

### 6. 认同感（1-5分）
**定义**：用户是否认同内容表达的观点和价值观

**评分标准**：
- 5分：高度认同，观点完全符合其价值观
- 4分：比较认同，大部分观点接受
- 3分：部分认同，部分观点有保留
- 2分：不太认同，大部分观点质疑
- 1分：完全不认同，观点与其价值观冲突

### 7. 感动/触动性（1-5分）
**定义**：内容是否能够触动用户的情感

**评分标准**：
- 5分：强烈触动，情感共鸣明显
- 4分：有一定触动，情感有波动
- 3分：轻微触动，有情感反应
- 2分：触动微弱，情感反应不明显
- 1分：无触动，情感无反应

### 8. 行动感染力（1-5分）
**定义**：内容是否能够激发用户采取行动（如购买、转发、搜索等）

**评分标准**：
- 5分：强烈感染力，会立即采取行动
- 4分：有感染力，可能会采取行动
- 3分：感染力一般，行动意愿不强
- 2分：感染力较弱，不太可能采取行动
- 1分：无感染力，不会采取行动

## 四、评估流程

### 传播计划书评估
1. 构建模拟目标用户
2. 让用户"阅读"传播计划书
3. 用户基于自身特征和偏见进行评估
4. 输出8维度打分和总得分
5. 根据总得分决定是否需要优化

### 稿件评估
1. 对每篇稿件分别评估
2. 模拟用户"阅读"稿件
3. 基于用户特征和偏见进行8维度打分
4. 计算每篇稿件总得分
5. 根据得分决定是否需要优化

### 五、评分标准

### 网感专项评分（最高优先级）

**网感等级映射到1-5分**：
- S级（90-100分）→ 5分
- A级（80-89分）→ 4分
- B级（70-79分）→ 3分
- C级（60-69分）→ 2分
- D级（60分以下）→ 1分

**决策规则**：
- **网感指数 < 4分**：直接重写/拒绝，不允许进入后续评估
- **网感指数 ≥ 4分**：进入8维度评估流程

### 前8维度总得分计算（网感≥4分后执行）

- 总得分 = 8个维度的平均分
- 保留一位小数

### 最终决策规则

**两阶段评估流程**：

**第一阶段：网感专项评估**
1. 计算网感得分（根据内容类型）
2. 判定网感等级（S/A/B/C/D）
3. 映射为网感指数（1-5分）
4. **网感指数 < 4分**：直接重写/拒绝，停止评估
5. **网感指数 ≥ 4分**：进入第二阶段

**第二阶段：8维度评估**
1. 对8维度分别打分（1-5分）
2. 计算总得分 = 8个维度的平均分
3. **总得分 ≥ 4.0**：通过评估，直接展示
4. **总得分 3.0-3.9**：根据评估意见优化后展示
5. **总得分 < 3.0**：重新创作

### 评语要求

**网感评估评语**：
- 必须明确指出网感问题
- 必须提供具体改进建议
- 必须体现内容类型的网感特征

**8维度评估评语**：
- 评语必须体现模拟用户的偏见和特征
- 评语要具体，避免笼统
- 如需改进，提供具体建议

## 六、典型偏见示例

### 95后Z世代（25-29岁）
- **代际偏见**："70后80后都是说教"、"90后不懂真正的自由"
- **产业偏见**："互联网行业才是未来"、"传统行业没前途"
- **内容偏好**：短视频、二次元、游戏、国潮、社交话题
- **近期关注**：职场焦虑、买房压力、社交恐惧、躺平vs内卷

### 80后中产（35-40岁）
- **代际偏见**："95后眼高手低吃不了苦"、"00后太脆弱"
- **产业偏见**："实体经济才是根本"、"虚拟经济都是泡沫"
- **内容偏好**：财经、教育、育儿、健康、职场管理
- **近期关注**：子女教育、资产配置、健康养生、职场晋升

### 下沉市场用户（30-45岁）
- **代际偏见**："城市人太矫情"、"年轻人不踏实"
- **产业偏见**："大厂都是坑"、"踏实干活最重要"
- **内容偏好**：生活记录、情感故事、实用技能、励志逆袭
- **近期关注**：赚钱、家庭、亲情、奋斗故事

### 科技从业者（28-35岁）
- **代际偏见**："传统行业效率太低"、"管理层不懂技术"
- **产业偏见**："互联网公司都在收割"、"开源才是未来"
- **内容偏好**：技术前沿、产品思维、行业分析、创业故事
- **近期关注**：AI技术、裁员潮、薪资、职业发展

### 职场女性（25-35岁）
- **性别偏见**："男性更适合技术岗"、"女性要顾家"
- **代际偏见**："老一辈思想落后"、"年轻人不懂责任"
- **内容偏好**：职场成长、女性话题、生活美学、心理健康
- **近期关注**：职业发展、婚恋压力、自我提升、生活平衡
