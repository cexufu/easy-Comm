# 短视频文案撰写规则（吸引力第一法则版）

## ⚠️ 核心原则：吸引力第一法则！

**好的短视频的价值在于触动，在于吸引人们流量之后，让用户停留、完播、评论。在端氏皮的逻辑里，吸引力是第一法则，它会穷尽一切可能留住你，并且改变你，哪怕为此要牺牲一些规则和东西，在平台、内容创作者都是可以接受的。**

短视频价值 = 触动 + 停留 + 完播 + 评论
吸引力第一法则 = 穷尽一切可能留住用户 + 改变用户 + 可以牺牲规则和东西

## 一、短视频价值逻辑（底层逻辑）

### 核心公式

**短视频价值 = 触动 + 停留 + 完播 + 评论**

### 四大核心要素

#### 要素1：触动（情感冲击）

**定义**：内容能够触动用户的情感

**核心策略**：
- 情绪冲击：痛苦、激动、感动、遗憾、愤怒
- 共鸣引发：说到了心坎里、这就是我
- 情绪递进：小情绪→中情绪→大情绪→情绪高潮

**反面示例**：
❌ 情绪平淡、无冲击力
✓ 情绪强烈、直击人心

---

#### 要素2：停留（前3秒生死线）

**定义**：用户愿意停留观看

**核心策略**：
- 前3秒钩子：震惊、悬念、冲突、情绪、价值
- 每5秒信息点：确保全程无尿点
- 节奏紧凑：快速切入、无废话

**反面示例**：
❌ 前3秒无钩子、节奏拖沓
✓ 前3秒有钩子、节奏紧凑

---

#### 要素3：完播（全程情绪在线）

**定义**：用户愿意看完整个视频

**核心策略**：
- 情绪全程在线：每10秒必须有情绪波动
- 高潮前置：高潮要在前半段（15-20秒）
- 反转精炼：反转不要超过3次

**反面示例**：
❌ 全程无情绪波动、高潮放最后
✓ 全程情绪在线、高潮前置

---

#### 要素4：评论（互动引导）

**定义**：用户愿意评论、互动

**核心策略**：
- 自然引导：双击屏幕、点赞收藏、关注我
- 具体引导：评论区告诉我、A还是B
- 有吸引力：挑战一下、看谁做得更好

**反面示例**：
❌ 无互动引导、引导生硬
✓ 互动引导明确有力

## 二、吸引力第一法则（核心）

### 法则定义

**吸引力第一法则：穷尽一切可能留住用户，改变用户，哪怕为此要牺牲一些规则和东西，在平台、内容创作者都是可以接受的。**

### 三大核心特征

**特征1：穷尽一切可能**
- 用尽一切手段留住用户
- 不遗余力改变用户
- 想尽办法触动用户

**特征2：可以牺牲规则**
- 可以牺牲部分规则
- 可以牺牲部分原则
- 可以牺牲部分常规

**特征3：平台可接受**
- 平台为了留住用户，可以接受牺牲规则
- 创作者为了改变用户，可以接受牺牲规则
- 用户为了获得触动，可以接受牺牲规则

### 注意事项

**注意**：
- 牺牲规则不等于违法违规
- 牺牲规则不等于违背道德
- 牺牲规则不等于伤害用户

## 三、吸引力4大维度（第一优先级）

### 吸引力定义

**吸引力是指内容在第一眼就能抓住用户注意力的能力。**

### 维度1：钩子强度（权重35%）

**定义**：前3秒是否能瞬间抓住用户注意力

**评估标准**：
- 钩子是否具有强烈冲突
- 钩子是否具有强烈悬念
- 钩子是否具有强烈情绪
- 钩子是否具有强烈好奇

**吸引力特征**：
✓ "太震惊了！"
✓ "绝对没想到！"
✓ "差点要了命！"
✓ "颠覆认知！"

**反面示例**：
❌ "今天分享XX"（无吸引力）
✓ "太震惊了！XX差点要了我的命！"（强吸引力）

---

### 维度2：冲突强度（权重30%）

**定义**：内容是否有足够强烈的冲突和矛盾

**评估标准**：
- 冲突是否激烈
- 冲突是否尖锐
- 冲突是否有悬念
- 冲突是否有情绪
- 冲突是否多层递进

**吸引力特征**：
✓ "VS"对抗强烈
✓ "反转"出人意料
✓ "矛盾"尖锐对立
✓ "悬念"层层递进
✓ **多层冲突**（⚠️ 现代用户需求高，需要多层冲突才能留住人）

**反面示例**：
❌ 平铺直叙，无冲突
❌ 一次冲突，太单薄
✓ 冲突激烈，悬念十足
✓ 多层冲突，层层递进

---

### 多层冲突设计（⚠️ 核心技巧）

**参考文档**：[foundations/conflict-design.md](../foundations/conflict-design.md) - 冲突设计与合理性

**多层冲突的原则**：
1. **层层递进**：每一层冲突都要比前一层更强烈、更意外、更反转
2. **逻辑自洽**：多层冲突之间要有逻辑关联
3. **情感真实**：多层冲突要符合人物情感逻辑
4. **不是越多越好**：一般2-4层冲突最佳，超过4层会显得刻意

**多层冲突的密度控制**：
- 15-30秒：2层冲突（刚好）
- 30-45秒：3层冲突（最佳）
- 45-60秒：4层冲突（接近上限）

**多层冲突示例（前男友相见）**：
- **一次冲突**：女孩有了孩子（情感矛盾）
- **二次冲突**：孩子是前男友的（意外真相）
- **三次冲突**：前男友一直都知道，所以一直给女孩寄钱的陌生人是他（深层动机）
- **四次冲突**：女孩也知道是前男友寄钱，但是她其实也不想复合（反转选择）

**多层冲突示例（普通大爷）**：
- **一次冲突**：普通的大爷，竟然是北大教授（身份反转）
- **二次冲突**：大爷的儿子，竟然是公司的CEO（身份关联）
- **三次冲突**：CEO一直在暗中帮助公司，但没人知道（深层利益）
- **四次冲突**：CEO之所以帮助，是因为公司曾经帮助过大爷（反转选择）

**冲突合理性判断**：
- **逻辑自洽**：多层冲突之间要有逻辑关联
- **情感真实**：冲突要符合人物情感逻辑
- **人设符合**：冲突要符合人物人设
- **注意**：不合理的冲突会导致"逻辑断裂、情感虚假、人设崩塌"

### 搞笑赛道的冲突设计（⚠️ 独立赛道）

**搞笑赛道的特殊性**：
- **可以无厘头**：逻辑可以不通，情节可以荒诞，规则可以打破
- **可以反常识**：可以违背常识，可以不符合现实，可以超现实
- **可以荒诞**：可以极度夸张，可以不合逻辑，可以天马行空
- **但要有笑点**：无厘头要有笑点，反常识要有笑点，荒诞要有笑点

**搞笑冲突的设计技巧**：
1. **无厘头反转**：正常开头 → 无厘头转折 → 更无厘头反转
2. **反常识设定**：正常设定 → 反常识揭示 → 更反常识反转
3. **荒诞升级**：荒诞事件 → 更荒诞的解释 → 最荒诞的真相
4. **极度夸张**：正常事件 → 极度夸张 → 极度夸张的真相

**搞笑冲突示例（筷子夹山）**：
- **一次冲突**：男人用筷子夹起了一座山（无厘头事件）
- **二次冲突**：山其实是蛋糕做的（荒诞解释）
- **三次冲突**：蛋糕是外星人送的（更荒诞的真相）
- **四次冲突**：外星人其实是男人未来的自己（终极反转）

**搞笑冲突的注意**：
- **要有笑点**：不能为了搞笑而搞笑
- **不能太刻意**：要有内在逻辑
- **不能低俗**：不能低俗、恶俗、违法违规
- **适合搞笑赛道**：搞笑赛道特别适合传播，尤其是无厘头状态

## 四、网感核心指标（第二优先级）

### 三大优先级

**第一优先级：网感**
- 网感是生命线，没有网感就没有流量
- 网感5大维度：钩子强度、反差度、节奏感、情绪强度、互动引导
- 网感<4分：直接重写，不允许通过

**第二优先级：长度限制**
- 长度是硬要求，不可妥协
- 短视频：15-45秒最佳，超过60秒直接不合格
- 前3秒必须有钩子
- 每10秒必须有信息点

**第三优先级：情绪冲击**
- 情绪冲击是加分项，不是核心
- 在保证网感和长度的基础上，尽量增加情绪冲击
- 情绪冲击不能损伤网感和长度

### 优先级执行规则

1. **网感第一**：所有内容必须先满足网感要求
2. **长度第二**：在满足网感的基础上，严格控制长度
3. **情绪第三**：在满足网感和长度的基础上，增强情绪冲击

**禁止**：
- ❌ 为了情绪冲击牺牲网感
- ❌ 为了情绪冲击增加长度
- ❌ 为了情绪冲击破坏节奏

## 二、网感核心指标（第一优先级）

### 网感定义

**网感是指创作者对短视频平台用户注意力规律、内容节奏、情绪控制的专业理解和运用能力。**

### 网感5大维度（专项评分）

#### 维度1：钩子强度（权重30%）

**定义**：前3秒是否能瞬间抓住用户注意力

**评估标准**：
- 钩子是否具有冲突性
- 钩子是否具有悬念性
- 钩子是否具有情绪性
- 钩子是否具有相关性

**网感特征**：
✓ "你绝对想不到..."
✓ "99%的人都不知道..."
✓ "我差点就..."
✓ "千万别..."

**反面示例**：
❌ "今天给大家分享XX"（平淡无奇）
✓ "这个方法差点害了我！"（强钩子）

**评分标准**：
- 30分：超强钩子，用户一定会看下去
- 24分：强钩子，大部分用户会看下去
- 18分：中强钩子，一半用户会看下去
- 12分：弱钩子，少数用户会看下去
- 6分：无钩子，用户直接划走

---

#### 维度2：反差度（权重25%）

**定义**：内容是否有足够强烈的反差和转折

**评估标准**：
- 是否有预期反转
- 是否有身份反转
- 是否有结果反转
- 是否有情绪反转

**网感特征**：
✓ "我以为...结果..."
✓ "看似...实则..."
✓ "本想...却意外..."
✓ "没想到最后..."

**反面示例**：
❌ 平铺直叙，无反差
✓ 多层反转，意外连连

**评分标准**：
- 25分：3层以上反转，反差极大
- 20分：2层反转，反差明显
- 15分：1层反转，有一定反差
- 10分：预期之内，反差较小
- 5分：无反转，无反差

---

#### 维度3：节奏感（权重20%）

**定义**：视频节奏是否符合短视频平台的观看习惯

**评估标准**：
- 节奏是否紧凑不拖沓
- 信息密度是否适中
- 画面切换是否流畅
- 音乐卡点是否精准

**网感特征**：
✓ 节奏紧凑，无废话
✓ 信息密集，高价值
✓ 画面切换，有变化
✓ 音乐卡点，有氛围

**反面示例**：
❌ 节奏缓慢，拖沓冗长
✓ 节奏紧凑，爽快淋漓

**评分标准**：
- 20分：节奏完美，全程无尿点
- 16分：节奏良好，少数拖沓
- 12分：节奏一般，部分拖沓
- 8分：节奏较差，多处拖沓
- 4分：节奏很差，全程拖沓

---

#### 维度4：情绪强度（权重15%）

**定义**：内容是否能激发用户的情绪反应

**评估标准**：
- 情绪是否到位
- 情绪是否递进
- 情绪是否有峰值
- 情绪是否能共鸣

**网感特征**：

✓ 情绪递进，层层升华
✓ 情绪峰值，冲击力强

✓ 情绪饱满，直击人心

- 9分：情绪一般，少量共鸣
- 6分：情绪较弱，无明显共鸣
- 3分：情绪极弱，无共鸣

---

## 三、前3秒钩子（生死线）

### 前3秒的重要性

**数据支撑**：
- 用户在前3秒划走率：60-70%
- 前3秒决定视频的生死
- 前3秒钩子不够，后面再精彩也没用

**执行标准**：
- 前3秒必须有钩子
- 钩子必须是"强钩子"
- 钩子必须在第1秒出现

### 前3秒钩子5大类型

#### 类型1：冲突钩子（最有效）

**定义**：制造强烈的冲突和矛盾，瞬间抓住注意力

**公式**："冲突 + 反常识"

**示例**：
- "这个方法差点害了我！"
- "99%的人都做错了！"
- "我差点因为这件事破产！"
- "千万别再这样做了！"

**网感要素**：
✓ 冲突强烈
✓ 反常识
✓ 有悬念
✓ 有情绪

**反面示例**：
❌ "今天分享一个XX方法"（无冲突）
✓ "这个方法差点害了我！"（强冲突）

---

#### 类型2：悬念钩子

**定义**：制造悬念，让用户想看答案

**公式**："悬念 + 未知 + 答案在后面"

**示例**：
- "你绝对想不到..."
- "最后的结果让人震惊！"
- "你猜最后怎么了？"
- "答案就在最后！"

**网感要素**：
✓ 悬念强烈
✓ 未知感强
✓ 想看答案
✓ 好奇心驱动

**反面示例**：
❌ "今天说说XX"（无悬念）
✓ "你绝对想不到..."（强悬念）

---

#### 类型3：结果钩子

**定义**：先展示结果，再解释原因

**公式**："结果 + 反差 + 原因"

**示例**：
- "3天瘦了5斤，我是怎么做到的？"
- "月薪5000到5万，我只做对了一件事！"
- "从负债到买房，这3年我经历了什么？"
- "3个月涨粉100万，我的秘密都在这里！"

**网感要素**：
✓ 结果惊人
✓ 反差巨大
✓ 引发好奇
✓ 想要知道方法

**反面示例**：
❌ "分享一下XX的方法"（无结果）
✓ "3天瘦了5斤，我是怎么做到的？"（强结果）

---

#### 类型4：情绪钩子

## 四、情绪冲击辅助（第三优先级）

### 情绪冲击定义

**情绪冲击是在保证网感和长度的基础上，增强内容的情绪感染力。**

### 情绪冲击原则

**原则1：不损伤网感**
- 情绪冲击不能破坏钩子强度
- 情绪冲击不能破坏节奏感
- 情绪冲击不能破坏反差度

**原则2：不增加长度**
- 情绪冲击不能增加视频时长
- 情绪冲击不能占用太多时间
- 情绪冲击要简洁有力

**原则3：简洁有力**
- 情绪冲击要短小精悍
- 情绪冲击要一针见血
- 情绪冲击要瞬间爆发

**情绪冲击要素**：

## 五、反差与转折

### 反差的重要性

**反差是短视频的灵魂，没有反差就没有记忆点。**

**反差的作用**：
- 抓住注意力
- 制造惊喜
- 增强记忆
- 促进传播

### 反差5大类型

#### 类型1：预期反差

**定义**：用户的预期与实际结果相反

**公式**："以为A，结果是B"

**示例**：
- "我以为这方法没用，结果一试就惊呆了！"
- "本以为是个坑，没想到是宝藏！"
- "我以为会很复杂，结果3步就搞定了！"
- "我以为会失败，没想到竟然成功了！"

**网感要素**：
✓ 预期明确
✓ 反差明显
✓ 惊喜感强
✓ 记忆点深

---

#### 类型2：身份反差

**定义**：身份或地位的反转

**公式**："看起来A，实际是B"

**示例**：
- "看似普通的大爷，竟然是北大教授！"
- "看起来像20岁，实际已经50岁了！"
- "看似豪车车主，其实是跑网约车的！"
- "看起来像个新手，实际是10年老手！"

**网感要素**：
✓ 身份反差
✓ 出人意料
✓ 制造好奇
✓ 激发讨论

---

#### 类型3：结果反差

**定义**：付出与结果的反转

**公式**："付出了A，得到了B（意外的）"

**示例**：
- "花了100块，买到了价值1000块的效果！"
- "只用了1小时，完成了别人1天的工作！"
- "放弃了高薪工作，反而过得更好！"
- "本想省钱，结果花了更多！"

**网感要素**：
✓ 投入产出反差
✓ 意外之喜/意外之惊
✓ 引发思考
✓ 传播性强

---

#### 类型4：情绪反差

**定义**：情绪的突然转变

**公式**："情绪A → 情绪B（突然）"

**示例**：
- "本来很沮丧，突然看到了这个，瞬间破防！"
- "本来很平静，突然被这件事感动哭了！"
- "本来很生气，突然想到这件事，气消了！"
- "本来很开心，突然听到这个，崩溃了！"

**网感要素**：
✓ 情绪转换
✓ 突然性
✓ 冲击力强
✓ 共鸣感强

---

#### 类型5：时间反差

**定义**：时间上的反转

**公式**："过去A，现在B（反差）"

**示例**：
- "从月薪3000到月薪10万，我只用了一年！"
- "3年前我还是个新手，现在已经是行业专家！"
- "从负债50万到存款500万，这3年我经历了什么？"
- "从被嘲笑到被羡慕，我是如何逆袭的？"

**网感要素**：
✓ 时间跨度
✓ 前后反差
✓ 成长轨迹
✓ 励志感强

---

### 反差层数（重要）

**1层反差**：
- "我以为A，结果是B"
- 反差一般，效果一般

**2层反差**：
- "我以为A，结果是B，最后发现是C"
- 反差明显，效果较好

**3层反差**（最佳）：
- "我以为A，结果是B，然后发现是C，最后真相是D"
- 反差极大，效果最佳

**示例**：
```
1层反差：
我以为这个产品没用（A），结果一用就惊呆了（B）

2层反差：
我以为这个产品没用（A），结果一用就惊呆了（B），最后发现只花了10块钱（C）

3层反差：
我以为这个产品没用（A），结果一用就惊呆了（B），最后发现只花了10块钱（C），原来是我一直买错了品牌（D）
```

**反差层数评分**：
- 3层反差：25分（满分）
- 2层反差：20分
- 1层反差：15分
- 0层反差：5分

## 六、完播率保障（核心目标）

### 完播率的重要性

**完播率是短视频的核心指标，决定了视频的流量分配。**

**数据支撑**：
- 完播率<30%：平台几乎不推荐
- 完播率30-50%：平台少量推荐
- 完播率50-70%：平台大量推荐
- 完播率>70%：平台爆发推荐

### 完播率保障法则

**法则1：前3秒生死线**
- 第1秒必须有钩子
- 第3秒必须有期待
- 前3秒决定用户是否会看下去

**法则2：每5秒信息点**
- 每5秒必须有信息输出
- 每5秒必须有画面变化
- 每5秒必须有节奏变化
- 确保用户全程无尿点

**法则3：情绪全程在线**
- 每10秒必须有情绪波动
- 情绪不能平淡
- 情绪不能断层
- 情绪必须递进

**法则4：高潮前置**
- 高潮不要放最后
- 高潮要在前半段（15-20秒）
- 高潮要有冲击力
- 高潮后立即引导互动

**法则5：反转不超3次**
- 反转要精炼
- 反转要有力
- 反转不要超过3次
- 反转要在15-35秒内完成

### 完播率提升技巧

#### 技巧1：悬念式推进

**公式**："悬念 → 揭秘 → 新悬念 → 新揭秘"

**示例**：
"你绝对想不到（悬念），我用了这个方法（揭秘），结果3天就瘦了5斤（新悬念），方法就在最后（新揭秘）！"

**网感要素**：
✓ 悬念层层推进
✓ 揭秘有惊喜
✓ 想看下去
✓ 好奇心驱动

---

#### 技巧2：情绪式递进

**公式**："小情绪 → 中情绪 → 大情绪 → 情绪高潮"

**示例**：
"一开始觉得不靠谱（小情绪），后来试了一下还不错（中情绪），用了一周效果特别好（大情绪），现在我已经离不开它了（情绪高潮）！"

**网感要素**：
✓ 情绪递进
✓ 层层升级
✓ 感染力强
✓ 共鸣感强

---

#### 技巧3：反差式惊喜

**公式**："反差1 → 反差2 → 反差3 → 最终真相"

**示例**：
"我以为这个产品没用（反差1），结果一用就惊呆了（反差2），最后发现只花了10块钱（反差3），原来是我一直买错了品牌（最终真相）！"

**网感要素**：
✓ 反差层层
✓ 惊喜不断
✓ 想知道真相
✓ 记忆深刻

---

### 完播率禁忌

❌ 前3秒无钩子
❌ 全程无情绪波动
❌ 信息点稀疏（每5秒无信息点）
❌ 高潮放最后
❌ 反转过多（超过3次）

✓ 前3秒有钩子
✓ 全程情绪在线
✓ 每5秒有信息点
✓ 高潮前置（15-20秒）
✓ 反转精炼（不超过3次）

### 信息密度评分

- **每10秒有信息点**：不扣分
- **每15秒有信息点**：扣10分
- **每20秒有信息点**：扣20分

## 九、网感评分体系

### 网感评分计算

**总分 = 100分**

**维度得分**：
- 钩子强度：30分
- 反差度：25分
- 节奏感：20分
- 情绪强度：15分
- 互动引导：10分

**扣分项**：
- 超60秒：-30分（每超10秒）
- 前3秒无钩子：-30分
- 无反差：-20分
- 节奏拖沓：-15分
- 无互动引导：-5分

### 网感等级

- **S级（90-100分）**：网感极佳，爆款潜力
- **A级（80-89分）**：网感优秀，有潜力
- **B级（70-79分）**：网感良好，需优化
- **C级（60-69分）**：网感一般，需改进
- **D级（60分以下）**：网感差，必须重写

### 网感评分纳入9维度评估

在模拟用户评估的9维度中，短视频的"网感指数"基于上述5维度评分：

**9. 网感指数（1-5分）**
- 5分：网感极佳（S级）
- 4分：网感优秀（A级）
- 3分：网感良好（B级）
- 2分：网感一般（C级）
- 1分：网感差（D级）

**决策规则**：
- 网感指数 < 4分：直接重写，不允许通过
- 网感指数 ≥ 4分：才进入后续评估流程

## 十一、黄金节奏法则

### 节奏核心法则

**法则1：前3秒生死线**
- 第1秒必须有钩子
- 第3秒必须有期待

**法则2：每10秒信息点**
- 每10秒必须有信息输出
- 每10秒必须有画面变化
- 每10秒必须有节奏变化

**法则3：全程无尿点**
- 无废话
- 无重复
- 无拖沓
- 无停顿

**法则4：高潮前置**
- 高潮不要放最后
- 高潮要在前半段
- 高潮要有冲击力

### 节奏把控技巧

#### 技巧1：语速控制

**快速语速**：营造紧张感、兴奋感
**慢速语速**：强调重点、制造悬念
**快慢结合**：节奏变化、避免单调

#### 技巧2：画面切换

**画面切换频率**：
- 每5-10秒切换一次画面
- 快节奏：3-5秒切换
- 慢节奏：10-15秒切换

**画面切换原则**：
- 同景别不切换
- 同角度不切换
- 同内容不切换

#### 技巧3：音乐卡点

**卡点原则**：
- 关键节点卡音乐
- 情绪高潮卡音乐
- 转换节点卡音乐
- 结尾收尾卡音乐

## 十四、避坑指南

### 网感杀手（必须避免）

❌ **无钩子开头**
- "今天分享一下XX"
- "大家好我是XX"
- "今天天气不错..."

✓ **强钩子开头**
- "这个方法差点害了我！"
- "你绝对想不到..."
- "3天瘦了5斤，我是怎么做到的？"

❌ **无反差转折**
- 平铺直叙，无反转
- 预期之内，无惊喜

✓ **多层反差**
- 3层反差，意外连连
- 出人意料，惊喜不断

❌ **节奏拖沓**
- 节奏缓慢，废话多
- 信息密度低，无价值

✓ **节奏紧凑**
- 快速切入，高价值
- 全程无尿点，爽快

❌ **无互动引导**
- 自说自话，不互动
- 无点赞收藏引导

✓ **互动有力**
- 互动引导明确
- 引导点赞收藏关注

❌ **超时长**
- 单个视频超过60秒
- 前3秒无钩子

✓ **控制时长**
- 15-45秒最佳
- 前3秒必有钩子

❌ **情绪冲击过长**
- 超过3秒还在铺垫情绪
- 情绪冲击拖慢节奏

✓ **情绪冲击简洁**
- 情绪冲击短小精悍
- 瞬间爆发，不拖沓
