## 一、优先级体系（最高优先级）

### 三大优先级

**第一优先级：网感**
- 网感是生命线，没有网感就没有流量
- 网感5大维度：原生感、即时感、亲近感、节奏感、社交货币
- 网感<4分：直接重写，不允许通过

**第二优先级：长度限制**
- 长度是硬要求，不可妥协
- 小红书：300-500字最佳，超过800字直接不合格
- 标题：10-20字最佳，超过30字直接不合格
- 正文：每100字必须有信息点

**第三优先级：情绪冲击**
- 情绪冲击是加分项，不是核心
- 在保证网感和长度的基础上，尽量增加情绪冲击
- 情绪冲击不能损伤网感和长度

### 优先级执行规则

1. **网感第一**：所有内容必须先满足网感要求
2. **长度第二**：在满足网感的基础上，严格控制长度
3. **情绪第三**：在满足网感和长度的基础上，增强情绪冲击

**禁止**：
- ❌ 为了情绪冲击牺牲网感
- ❌ 为了情绪冲击增加长度
- ❌ 为了情绪冲击破坏原生感

## 二、网感5大维度（第一优先级）

### 网感定义

**网感是指创作者对小红书平台用户偏好、内容风格、社交传播规律的专业理解和运用能力。**

### 维度1：原生感（权重25%）

**定义**：内容看起来像普通用户分享，而非官方宣传

**网感特征**：
✓ 使用"我""今天""终于"等第一人称
✓ 使用时间状语："昨天""刚才""刚刚"
✓ 使用情绪表达："太激动了""太感动了"
✓ 使用随意口语："真的""绝了""太香了"

**反面示例**：
❌ "本产品具有XX功能"（官方腔）
✓ "这个东西真的太香了！"（原生感）

**原生感公式**：
```
官方腔 → 口语化
产品介绍 → 个人体验
功能说明 → 真实感受
专业术语 → 大白话
```

**评分标准**：
- 25分：原生感极强，像真实用户分享
- 20分：原生感较强，略有宣传痕迹
- 15分：原生感一般，有较明显宣传痕迹
- 10分：原生感较弱，宣传痕迹明显
- 5分：原生感极弱，像官方广告

---

### 维度2：即时感（权重20%）

**定义**：内容有"刚刚发生""正在发生"的感觉

**网感特征**：
✓ 时间状语："今天""昨天""刚才""刚刚"
✓ 状态描述："终于""终于等到""终于搞定"
✓ 场景描述："刚刚收到""刚刚用完""刚刚发现"

**反面示例**：
❌ "使用XX产品可以..."（无即时感）
✓ "今天终于收到XX了！太激动了！"（即时感强）

**即时感公式**：
```
理论描述 → 即时体验
功能说明 → 刚刚发生
抽象介绍 → 具体场景
时间模糊 → 时间明确
```

**评分标准**：
- 20分：即时感极强，像刚发生的
- 16分：即时感较强，时间感明确
- 12分：即时感一般，时间感一般
- 8分：即时感较弱，时间感模糊
- 4分：即时感极弱，无时间感

---

### 维度3：亲近感（权重20%）

**定义**：内容让人感觉亲近，像闺蜜聊天

**网感特征**：
✓ 称呼："姐妹们""宝子们""集美们"
✓ 姿态："给大家分享""希望能帮到大家"
✓ 共情："有没有同感""谁懂啊"
✓ 互动："评论区告诉我""点赞收藏"

**反面示例**：
❌ "XX产品适合XX人群"（距离感）
✓ "姐妹们！这个真的太适合我们了！"（亲近感）

**亲近感公式**：
```
官方称呼 → 亲切称呼
产品推荐 → 闺蜜分享
功能说明 → 亲身体验
无互动 → 有互动
```

**评分标准**：
- 20分：亲近感极强，像闺蜜聊天
- 16分：亲近感较强，有亲切感
- 12分：亲近感一般，略有距离
- 8分：亲近感较弱，距离感明显
- 4分：亲近感极弱，像官方介绍

---

### 维度4：节奏感（权重20%）

**定义**：内容节奏紧凑，信息密集，无废话

**网感特征**：
✓ 段落短小：1-2句一段
✓ 信息密集：每100字有信息点
✓ 快速切入：开头直接进入主题
✓ 无废话：无冗余描述

**反面示例**：
❌ "XX产品是一个什么样的产品，它具有XX功能..."（啰嗦）
✓ "太香了！XX真的绝了！3步搞定XX！"（紧凑）

**节奏感公式**：
```
冗长描述 → 短小精悍
铺垫过长 → 快速切入
信息稀疏 → 信息密集
节奏缓慢 → 节奏紧凑
```

**评分标准**：
- 20分：节奏感极好，紧凑有力
- 16分：节奏感较好，有少量废话
- 12分：节奏感一般，有较多废话
- 8分：节奏感较差，啰嗦冗长
- 4分：节奏感极差，非常啰嗦

---

### 维度5：社交货币（权重15%）

**定义**：内容具有可分享、可讨论、可传播的价值

**网感特征**：
✓ 有话题性："有没有同感""谁懂啊"
✓ 有争议性："颠覆认知""没想到"
✓ 有共鸣性："说到了心坎里"
✓ 有实用性："学到了""涨知识了"

**反面示例**：
❌ "XX产品很好"（无社交货币）
✓ "学到了！这个方法真的太绝了！"（有社交货币）

**社交货币公式**：
```
平淡描述 → 话题性强
无争议 → 有争议性
无共鸣 → 有共鸣性
无价值 → 有实用性
```

**评分标准**：
- 15分：社交货币极强，易传播
- 12分：社交货币较强，有传播潜力
- 9分：社交货币一般，传播潜力一般
- 6分：社交货币较弱，传播潜力较弱
- 3分：社交货币极弱，无传播价值

## 三、标题规范（第一优先级）

### 标题重要性

**标题是内容的脸面，决定了用户是否会点击。**

**数据支撑**：
- 好标题点击率比差标题高3-5倍
- 标题决定了内容的80%命运
- 标题不好，内容再好也没人看

### 标题核心要素

**要素1：情绪词（必需）**

**情绪词清单**：
- 正向情绪：太激动、太感动、太开心、太惊喜、太幸福
- 负向情绪：太痛苦、太难受、太遗憾、太后悔、太愤怒
- 冲击情绪：差点崩溃、瞬间破防、心跳加速、起鸡皮疙瘩

**示例**：
✓ "太激动了！终于等到了！"
✓ "太痛苦了！这件事折磨了我整整3年！"

**要素2：数字（必需）**

**数字清单**：
- 时间：3天、7天、1个月、3年
- 次数：3步、5个、10个、100次
- 结果：瘦了5斤、涨粉10万、赚了100万

**示例**：
✓ "3步搞定XX！"
✓ "7天瘦了5斤！"

**要素3：身份（可选）**

**身份清单**：
- 学生党、上班族、宝妈、创业者
- 25岁、30岁、40岁
- 新手、小白、老手

**示例**：
✓ "所有学生党都看过来！"
✓ "30岁女性必看！"

### 标题3大公式

**公式1：情绪 + 数字 + 结果**

"太激动了！7天瘦了5斤！"

**公式2：情绪 + 身份 + 问题**

"太痛苦了！学生党熬夜党必看！"

**公式3：情绪 + 冲突 + 结果**

"太激动了！差点放弃，最后成功了！"

### 标题禁忌

❌ 超过30字
❌ 无情绪词
❌ 无数字
❌ 平淡无奇
❌ 官方腔调

✓ 10-20字
✓ 有情绪词
✓ 有数字
✓ 有冲突
✓ 口语化

## 四、开头技巧（第一优先级）

### 开头重要性

**开头是内容的钩子，决定了用户是否会继续看。**

**数据支撑**：
- 用户在前2秒决定是否继续看
- 好开头让用户看完全篇的概率提高5倍
- 开头不好，内容再好也没人看

### 开头3大技巧

**技巧1：情绪开头**

**公式**："情绪 + 时间 + 场景"

"太激动了！今天终于收到XX了！等了整整3年！"

**技巧2：冲突开头**

**公式**："冲突 + 反差 + 结果"

"差点放弃！本想退了，结果一用就惊呆了！"

**技巧3：数字开头**

**公式**："数字 + 结果 + 方法"

"3天瘦了5斤！我只做对了这3件事！"

### 开头禁忌

❌ 铺垫过长
❌ 无情绪无冲突
❌ 平淡无奇
❌ 官方腔调

✓ 快速切入
✓ 有情绪有冲突
✓ 有冲击力
✓ 口语化

## 五、正文结构（第一优先级）

### 黄金结构公式

```
第1段：开头（钩子）
├── 情绪开头："太激动了！今天终于收到XX了！"
├── 冲突开头："差点放弃！本想退了，结果一用就惊呆了！"
└── 数字开头："3天瘦了5斤！我只做对了这3件事！"

第2段：问题（共鸣）
├── 描述问题："这个问题困扰了我很久"
├── 描述痛苦："太痛苦了！折磨了我整整3年！"
└── 描述期待："一直想解决这个问题"

第3段：方法/产品（核心）
├── 介绍方法/产品："终于找到了解决方法"
├── 展示效果："一用就惊呆了！"
├── 描述体验："太香了！真的绝了！"
└── 情绪渲染："太激动了！终于搞定了！"

第4段：细节（补充）
├── 关键细节："特别要注意的是..."
├── 避坑指南："千万别..."
└── 经验分享："我是这么用的"

第5段：结尾（互动）
├── 总结收尾："真的很推荐给大家"
├── 互动引导："评论区告诉我"
├── 点赞收藏："记得点赞收藏"
└── 关注引导："关注我，下期分享更多"
```

### 正文5大原则

**原则1：段落短小**
每段1-2句，最多3句

**原则2：信息密集**
每100字有信息点

**原则3：情绪饱满**
使用情绪词，情绪化表达

**原则4：口语化**
使用口语，避免官方腔

**原则5：有互动**
引导用户点赞收藏评论

## 六、长度强制限制（第二优先级）

### 绝对禁止

❌ 标题超过30字
❌ 正文超过800字
❌ 正文少于300字
❌ 无信息点

### 推荐长度

- **标题**：10-20字（最佳）
- **正文**：300-500字（最佳）
- **信息密度**：每100字有信息点

### 长度评分规则

- **标题超30字**：直接不合格，网感得分为0
- **标题10-20字**：网感正常
- **标题10字以下**：网感扣10%

- **正文超800字**：扣网感分30%
- **正文500-800字**：网感正常
- **正文300-500字**：网感加15%
- **正文少于300字**：网感扣10%

- **信息密度评分**：
  - 每100字有信息点：不扣分
  - 每150字有信息点：扣10分
  - 每200字有信息点：扣20分
  - 超过200字无信息点：扣30%

## 七、情绪冲击辅助（第三优先级）

### 情绪冲击定义

**情绪冲击是在保证网感和长度的基础上，增强内容的情绪感染力。**

### 情绪冲击原则

**原则1：不损伤网感**
- 情绪冲击不能破坏原生感
- 情绪冲击不能破坏即时感
- 情绪冲击不能破坏亲近感

**原则2：不增加长度**
- 情绪冲击不能增加字数
- 情绪冲击不能占用太多篇幅
- 情绪冲击要简洁有力

**原则3：简洁有力**
- 情绪冲击要短小精悍
- 情绪冲击要一针见血
- 情绪冲击要瞬间爆发

### 情绪冲击5大类型

#### 类型1：激动型

**示例**：
- "太激动了！终于等到了！等了整整3年！"
- "太兴奋了！心跳都要跳出来了！"

**情绪冲击要素**：
✓ 时间累积（3年）
✓ 激动程度高
✓ 有生理反应（心跳加速）

---

#### 类型2：感动型

**示例**：
- "太感动了！看完这个我哭了整整一晚！"
- "太感人了！这个视频让我重新相信..."

**情绪冲击要素**：
✓ 时间累积（一整晚）
✓ 感动程度高
✓ 有生理反应（哭）

---

#### 类型3：痛苦型

**示例**：
- "太痛苦了！这件事折磨了我整整3年！"
- "太难受了！连续3个月失眠，差点崩溃！"

**情绪冲击要素**：
✓ 时间累积（3年/3个月）
✓ 痛苦程度高
✓ 有"差点"的效果

---

#### 类型4：遗憾型

**示例**：
- "太遗憾了！错过这个，我后悔了一辈子！"
- "太后悔了！如果早知道，我早就..."

**情绪冲击要素**：
✓ 时间累积（一辈子）
✓ 遗憾程度高
✓ 有"错过"的效果

---

#### 类型5：喜悦型

**示例**：
- "太开心了！今天终于收到XX了！"
- "太幸福了！这件事让我开心了整整一晚！"

**情绪冲击要素**：
✓ 时间累积（一整晚）
✓ 喜悦程度高
✓ 有具体场景

---

### 情绪冲击禁忌

❌ 情绪冲击过长：超过50字还在铺垫情绪
❌ 情绪冲击过弱："有点感动""有点惊讶"
❌ 情绪冲击破坏网感：情绪冲击破坏原生感/即时感/亲近感
❌ 情绪冲击增加长度：为了情绪冲击增加字数
❌ 情绪冲击空洞：情绪冲击没有具体内容支撑

✓ 情绪冲击简洁有力、瞬间爆发、不损伤网感、不增加长度、有具体场景

## 十、网感评分体系

### 网感评分计算

**总分 = 100分**

**维度得分**：
- 原生感：25分
- 即时感：20分
- 亲近感：20分
- 节奏感：20分
- 社交货币：15分

**扣分项**：
- 标题超30字：-20分
- 正文超800字：-30分（每超100字）
- 正文少于300字：-10分
- 无话题/标签：-5分
- 图片质量差：-10分

### 网感等级

- **S级（90-100分）**：网感极佳，爆款潜力
- **A级（80-89分）**：网感优秀，有潜力
- **B级（70-79分）**：网感良好，需优化
- **C级（60-69分）**：网感一般，需改进
- **D级（60分以下）**：网感差，必须重写

### 网感评分纳入9维度评估

在模拟用户评估的9维度中，小红书的"网感指数"基于上述5维度评分：

**9. 网感指数（1-5分）**
- 5分：网感极佳（S级）
- 4分：网感优秀（A级）
- 3分：网感良好（B级）
- 2分：网感一般（C级）
- 1分：网感差（D级）

**决策规则**：
- 网感指数 < 4分：直接重写，不允许通过
- 网感指数 ≥ 4分：才进入后续评估流程

## 十一、避坑指南

### 网感杀手（必须避免）

❌ **官方腔调**
- "本产品具有XX功能"
- "XX产品适合XX人群"

✓ **口语化表达**
- "这个东西真的太香了！"
- "姐妹们！这个真的太适合我们了！"

❌ **无即时感**
- "使用XX产品可以..."
- "XX产品具有XX功能"

✓ **即时感强**
- "今天终于收到XX了！太激动了！"
- "刚刚用完，效果真的太好了！"

❌ **无亲近感**
- "XX产品很好"
- "推荐大家使用"

✓ **亲近感强**
- "姐妹们！这个真的太适合我们了！"
- "希望能帮到大家！"

❌ **节奏拖沓**
- 段落过长，信息稀疏
- 铺垫太长，无信息点

✓ **节奏紧凑**
- 段落短小，信息密集
- 快速切入，高价值

❌ **无社交货币**
- 平淡描述，无话题性
- 无争议性，无共鸣性

✓ **社交货币强**
- "有没有同感""谁懂啊"
- "学到了""涨知识了"

❌ **标题平淡**
- 无情绪，无数字，无冲突

✓ **标题有冲击力**
- 有情绪词，有数字，有冲突

❌ **超长度**
- 标题超过30字
- 正文超过800字

✓ **控制长度**
- 标题10-20字
- 正文300-500字

❌ **情绪冲击过长**
- 超过50字还在铺垫情绪
- 情绪冲击破坏网感

✓ **情绪冲击简洁**
- 情绪冲击短小精悍
- 瞬间爆发，不拖沓
