## ⚠️ 核心原则：吸引力第一，网感第二，平台匹配度第三！

**吸引力是生死线，网感是生命线，平台匹配度是关键。**

吸引力 = 前3秒钩子 + 强烈冲突 + 情绪冲击 + 价值承诺

## 一、优先级体系（最高优先级）

### 三大优先级

**第一优先级：吸引力**
- 吸引力是生死线，没有吸引力就没有流量
- 吸引力4大维度：钩子强度、冲突强度、情绪强度、价值强度
- 吸引力<4分：直接重写，不允许通过

**第二优先级：网感**
- 网感是生命线，没有网感就没有推荐
- 网感4大维度：抖音风格、节奏紧凑、音乐卡点、互动引导
- 网感<4分：直接重写，不允许通过

**第三优先级：平台匹配度**
- 平台匹配度是关键，不匹配就没有流量
- 平台匹配度3大维度：用户偏好、内容调性、推荐机制
- 平台匹配度<4分：直接重写，不允许通过

### 优先级执行规则

1. **吸引力第一**：所有内容必须先满足吸引力要求
2. **网感第二**：在满足吸引力的基础上，强化网感
3. **平台匹配度第三**：在满足吸引力和网感的基础上，优化平台匹配度

**禁止**：
- ❌ 为了平台匹配度牺牲吸引力
- ❌ 为了网感牺牲吸引力
- ❌ 为了网感牺牲平台匹配度

## 二、吸引力核心指标（第一优先级）

### 吸引力定义

**吸引力是指内容在第一眼就能抓住用户注意力的能力。**

### 吸引力4大维度

#### 维度1：钩子强度（权重35%）

**定义**：前3秒是否能瞬间抓住用户注意力

**评估标准**：
- 钩子是否具有强烈冲突
- 钩子是否具有强烈悬念
- 钩子是否具有强烈情绪
- 钩子是否具有强烈好奇

**吸引力特征**：
✓ "太震惊了！"
✓ "绝对没想到！"
✓ "差点要了命！"
✓ "颠覆认知！"

**反面示例**：
❌ "今天分享XX"（无吸引力）
✓ "太震惊了！XX差点要了我的命！"（强吸引力）

**评分标准**：
- 35分：超强钩子，用户一定会看下去
- 28分：强钩子，大部分用户会看下去
- 21分：中强钩子，一半用户会看下去
- 14分：弱钩子，少数用户会看下去
- 7分：无钩子，用户直接划走

---

#### 维度2：冲突强度（权重30%）

**定义**：内容是否有足够强烈的冲突和矛盾

**评估标准**：
- 冲突是否激烈
- 冲突是否尖锐
- 冲突是否有悬念
- 冲突是否有情绪

**吸引力特征**：
✓ "VS"对抗强烈
✓ "反转"出人意料
✓ "矛盾"尖锐对立
✓ "悬念"层层递进

**反面示例**：
❌ 平铺直叙，无冲突
✓ 冲突激烈，悬念十足

**评分标准**：
- 30分：冲突极其激烈，悬念层层
- 24分：冲突明显，有悬念
- 18分：冲突一般，有悬念
- 12分：冲突较弱，悬念较小
- 6分：无冲突，无悬念

---

#### 维度3：情绪强度（权重20%）

**定义**：内容是否能激发用户的强烈情绪反应

**评估标准**：
- 情绪是否强烈
- 情绪是否有冲击力
- 情绪是否有共鸣
- 情绪是否有传染力

**吸引力特征**：
✓ "太激动了！"
✓ "太痛苦了！"
✓ "太感动了！"
✓ "太愤怒了！"

**反面示例**：
❌ 情绪平淡，无冲击力
✓ 情绪强烈，直击人心

**评分标准**：
- 20分：情绪极强，强烈共鸣
- 16分：情绪较强，明显共鸣
- 12分：情绪一般，少量共鸣
- 8分：情绪较弱，无明显共鸣
- 4分：情绪极弱，无共鸣

---

#### 维度4：价值强度（权重15%）

**定义**：内容是否能提供明确的价值承诺

**评估标准**：
- 价值是否明确
- 价值是否具体
- 价值是否可感知
- 价值是否立即可得

**吸引力特征**：
✓ "3步搞定XX"
✓ "7天见效"
✓ "100%有效"
✓ "免费获取"

**反面示例**：
❌ 价值模糊，不可感知
✓ 价值明确，立即可得

**评分标准**：
- 15分：价值明确，立即可得
- 12分：价值较明确，较易获取
- 9分：价值一般，较难获取
- 6分：价值较弱，难获取
- 3分：无价值，无承诺

## 三、网感核心指标（第二优先级）

### 网感定义

**网感是指内容符合抖音平台用户偏好和内容调性的能力。**

### 网感4大维度

#### 维度1：抖音风格（权重35%）

**定义**：内容是否符合抖音的风格特征

**评估标准**：
- 是否符合抖音用户偏好
- 是否符合抖音内容调性
- 是否符合抖音表达方式
- 是否符合抖音语言风格

**抖音风格特征**：
✓ 直接、干脆、不拖沓
✓ 有梗、有趣、有节奏
✓ 真实、接地气、有温度
✓ 有看点、有爆点、有亮点

**反面示例**：
❌ 官方腔、严肃、无趣
✓ 抖音风、有趣、有梗

**评分标准**：
- 35分：完全符合抖音风格
- 28分：基本符合抖音风格
- 21分：部分符合抖音风格
- 14分：不太符合抖音风格
- 7分：完全不符合抖音风格

---

#### 维度2：节奏紧凑（权重30%）

**定义**：视频节奏是否符合抖音的观看习惯

**评估标准**：
- 节奏是否紧凑不拖沓
- 信息密度是否适中
- 画面切换是否流畅
- 音乐卡点是否精准

**抖音节奏特征**：
✓ 快速切入，无废话
✓ 信息密集，高价值
✓ 画面切换，有变化
✓ 音乐卡点，有节奏

**反面示例**：
❌ 节奏缓慢，拖沓冗长
✓ 节奏紧凑，爽快淋漓

**评分标准**：
- 30分：节奏完美，全程无尿点
- 24分：节奏良好，少数拖沓
- 18分：节奏一般，部分拖沓
- 12分：节奏较差，多处拖沓
- 6分：节奏很差，全程拖沓

---

#### 维度3：音乐卡点（权重20%）

**定义**：音乐卡点是否符合抖音的内容节奏

**评估标准**：
- 音乐选择是否合适
- 卡点是否精准
- 音乐是否增强情绪
- 音乐是否强化记忆点

**抖音音乐特征**：
✓ 音乐有节奏、有氛围
✓ 卡点精准、强化情绪
✓ 音乐与内容匹配
✓ 音乐有记忆点

**反面示例**：
❌ 音乐不匹配、无节奏
✓ 音乐匹配、卡点精准

**评分标准**：
- 20分：音乐完美，卡点精准

- 12分：音乐一般，卡点一般
- 8分：音乐较差，卡点不准
- 4分：音乐很差，无卡点

## 五、前3秒钩子（生死线）

#### 类型1：震惊钩子（最有效）

**公式**："震惊 + 冲击 + 结果"

**示例**：
- "太震惊了！XX差点要了我的命！"
- "绝对没想到！XX竟然是这样！"
- "颠覆认知！XX原来才是真相！"

**吸引力要素**：
✓ 震感强烈
✓ 冲击力大
✓ 结果惊人

---

#### 类型2：悬念钩子

**公式**："悬念 + 未知 + 答案"

**示例**：
- "你绝对想不到最后发生了什么！"
- "你猜最后怎么了？答案让你震惊！"
- "想知道真相吗？一定要看到最后！"

**吸引力要素**：
✓ 悬念强烈
✓ 未知感强
✓ 想看答案

---

#### 类型3：冲突钩子

**公式**："冲突 + 对抗 + 结果"

**示例**：
- "VS！XX对决XX，结果让人震惊！"
- "冲突升级！XX和XX到底谁赢了？"
- "反转！XX竟然输了！"

**吸引力要素**：
✓ 冲突激烈
✓ 对抗强烈
✓ 结果出人意料

---

#### 类型4：情绪钩子

**公式**："情绪 + 场景 + 共鸣"

**示例**：

- "太感动了！看完这个我哭了整整一晚！"

**吸引力要素**：
✓ 情绪强烈
✓ 场景具体
✓ 共鸣感强

---

#### 类型5：价值钩子

**公式**："价值 + 承诺 + 立即可得"

```
├── 反转出现
├── 结果揭晓

└── 价值强化

45-60秒：互动（引导互动）
├── 总结收尾

├── 关注引导
└── 下期预告
```

## 十一、长度强制限制

### 绝对禁止

❌ 单个视频超过60秒
❌ 前3秒无钩子
❌ 每5秒无信息点
❌ 全程无高潮

### 推荐时长

- **短视频**：15-45秒（最佳）
- **中长视频**：45-60秒（可以接受）
- **前3秒**：必须有钩子
- **每5秒**：必须有信息点

- **A级（80-89分）**：网感优秀，有潜力
- **B级（70-79分）**：网感良好，需优化
- **C级（60-69分）**：网感一般，需改进
- **D级（60分以下）**：网感差，必须重写

### 决策规则

- 网感<4分：直接重写，不允许通过
- 网感≥4分：进入平台匹配度评估
