# 小红书图片Prompt生成规则

## 核心原则

**图片是小红书内容的门面，决定了用户是否会点进来。**

**目标**：生成高质量的图片Prompt，让用户可以直接用Prompt去AI绘图工具生成符合小红书风格的图片。

## 一、小红书图片风格特征

### 核心特征

**特征1：真实感**
- 像真实用户拍摄的照片
- 有生活气息
- 不刻意、不摆拍

**特征2：美观度**
- 色彩明亮、饱和度高
- 构图简洁、主题突出
- 光线柔和、质感好

**特征3：场景化**
- 有明确的场景背景
- 有生活化的元素
- 有氛围感

**特征4：细节丰富**
- 细节清晰、不模糊
- 有质感、有层次
- 有故事性

## 二、Prompt生成核心要素

### 核心要素6大件

**要素1：主体描述（必需）**

**公式**："主体 + 数量 + 外观 + 动作/状态"

**示例**：
- "一位年轻女性，穿着白色T恤和牛仔裤，手持一杯咖啡"
- "一个精致的小桌子，上面放着一瓶护肤品和一本书"

**网感特征**：
✓ 主体明确
✓ 外观清晰
✓ 动作/状态具体

---

**要素2：场景描述（必需）**

**公式**："场景 + 环境 + 氛围"

**示例**：
- "在阳光明媚的咖啡馆，背景有绿植和窗户"
- "在温馨的卧室，床上铺着米色的床单"
- "在明亮的书房，书桌上放着笔记本电脑"

**网感特征**：
✓ 场景明确
✓ 环境真实
✓ 氛围到位

---

**要素3：光线描述（必需）**

**公式**："光线类型 + 光线方向 + 光线效果"

**示例**：
- "柔和的自然光，从左侧窗户射入，形成明暗对比"
- "温暖的暖光，从上方照射，营造温馨氛围"
- "明亮的日光，从右侧照射，清晰明亮"

**网感特征**：
✓ 光线类型明确
✓ 光线方向清晰
✓ 光线效果到位

---

**要素4：构图描述（必需）**

**公式**："构图方式 + 主体位置 + 视角"

**示例**：
- "中心构图，主体位于画面中心，俯视视角"
- "三分法构图，主体位于右下角，平视视角"
- "特写构图，主体充满画面，近距离特写"

**网感特征**：
✓ 构图方式明确
✓ 主体位置清晰
✓ 视角独特

---

**要素5：色彩描述（必需）**

**公式**："主色调 + 辅助色 + 色彩氛围"

**示例**：
- "暖色调，以米色、粉色为主，营造温馨氛围"
- "冷色调，以蓝色、白色为主，营造清新氛围"
- "高饱和度，以橙色、黄色为主，营造活力氛围"

**网感特征**：
✓ 主色调明确
✓ 辅助色搭配合理
✓ 色彩氛围到位

---

**要素6：风格描述（必需）**

**公式**："风格类型 + 风格细节 + 风格氛围"

**示例**：
- "ins风，简洁大气，有设计感"
- "日系风，清新自然，有生活气息"
- "韩系风，精致时尚，有潮流感"

**网感特征**：
✓ 风格类型明确
✓ 风格细节到位
✓ 风格氛围符合小红书

## 四、Prompt生成技巧

### 技巧1：匹配文案风格

**原则**：图片Prompt必须与文案风格保持一致

**示例**：
- 文案风格：营销风格 → 图片风格：产品展示图、对比图
- 文案风格：品牌风格 → 图片风格：细节特写图、生活场景图
- 文案风格：素人风格 → 图片风格：使用场景图、生活场景图

---

### 技巧2：突出核心卖点

**原则**：图片Prompt必须突出文案中的核心卖点

**示例**：
- 文案卖点："3天美白" → 图片Prompt：展示美白效果的对比图
- 文案卖点："温和不刺激" → 图片Prompt：展示温和质感的细节特写图
- 文案卖点："生活美学" → 图片Prompt：展示生活场景的生活场景图

---

### 技巧3：符合小红书审美

**原则**：图片Prompt必须符合小红书的审美风格

**小红书审美特征**：
✓ ins风：简洁、大气、有设计感
✓ 日系风：清新、自然、有生活气息
✓ 韩系风：精致、时尚、有潮流感
✓ 国风：复古、优雅、有文化气息

---

### 技巧4：注重细节质量

**原则**：图片Prompt必须注重细节描述

**细节要素**：
- 光线：明确光线类型、方向、效果
- 构图：明确构图方式、主体位置、视角
- 色彩：明确主色调、辅助色、色彩氛围
- 质感：明确材质、纹理、反光

---

### 技巧5：避免过度修饰

**原则**：图片Prompt要真实自然，避免过度修饰

**避免**：
❌ 过度滤镜
❌ 过度美化
❌ 过度摆拍
❌ 过度商业

**提倡**：
✓ 真实自然
✓ 生活气息
✓ 质感真实
✓ 有温度

## 六、Prompt质量检查

### 检查清单

- [ ] 主体描述是否清晰明确
- [ ] 场景描述是否具体真实
- [ ] 光线描述是否到位
- [ ] 构图描述是否合理
- [ ] 色彩描述是否协调
- [ ] 风格描述是否符合小红书
- [ ] 是否匹配文案风格
- [ ] 是否突出核心卖点
- [ ] 是否符合小红书审美
- [ ] 是否注重细节质量

### 质量评分

**满分100分**：
- 主体描述（20分）：清晰明确，无歧义
- 场景描述（20分）：具体真实，有氛围
- 光线描述（15分）：到位合理，有质感
- 构图描述（15分）：合理独特，有创意
- 色彩描述（15分）：协调美观，有氛围
- 风格描述（15分）：符合小红书，有特色

**评分标准**：
- 90-100分：优秀，可直接使用
- 80-89分：良好，可小幅优化
- 70-79分：一般，需要优化
- 60-69分：较差，需要重写
- 60分以下：不合格，必须重写

## 注意事项

- Prompt必须用英文，AI绘图工具更准确理解
- Prompt要简洁明确，避免冗余描述
- Prompt要具体细节，避免模糊抽象
- Prompt要符合小红书审美，避免过度商业化
- Prompt要匹配文案风格，确保一致性
- Prompt要突出核心卖点，增强吸引力

**核心原则：真实感+美观度+场景化+细节丰富=小红书爆款图片！**
