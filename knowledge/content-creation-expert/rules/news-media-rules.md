# 新闻稿/媒体稿/微信稿撰写规则（新闻性优先版）

## ⚠️ 核心原则：新闻性第一，信息增量第二，行为引导第三！

**新闻的价值在于新闻性，在于让人们看到点进去，了解新信息，并且为这个新信息付出"关注"或者行为。**

新闻性 = 看到点进去 + 了解新信息 + 付出关注/行为
信息增量 = 新信息 + 深度信息 + 数据信息
行为引导 = 关注行为 + 互动行为 + 转化行为

## 一、新闻价值逻辑（底层逻辑）

### 核心公式

**新闻性 = 看到点进去 + 了解新信息 + 付出关注/行为**

### 三大核心要素

#### 要素1：看到点进去（吸引力）

**定义**：让用户第一眼就想点击了解

**核心策略**：
- 标题要有冲击力
- 导语要有悬念
- 开头要有冲突
- 视觉要有吸引力

**反面示例**：
❌ "XX公司发布新产品"
✓ "颠覆行业！XX发布的新产品让整个行业震惊！"

---

#### 要素2：了解新信息（信息增量）

**定义**：让用户获得新的、有价值的信息

**核心策略**：
- 信息要新
- 信息要独特
- 信息要有价值
- 信息要可验证

**反面示例**：
❌ 重复已知信息
✓ 提供独家信息、深度分析、数据支撑

---

#### 要素3：付出关注/行为（行为引导）

**定义**：让用户产生关注或行为

**核心策略**：
- 关注引导：关注账号、订阅媒体
- 行动引导：转发、分享、收藏
- 讨论引导：评论、参与话题
- 转化引导：购买、体验、使用

**反面示例**：
❌ 无行动引导
✓ 明确的行动引导：关注我们、转发分享、参与讨论

---

## 二、新闻性核心指标（最高优先级）

### 新闻性定义

**新闻性是指内容是否具有新闻价值，值得媒体报道和传播的程度。**

### 新闻性6大维度（专项评分）

#### 维度1：新鲜性（权重20%）

**定义**：内容是否具有时效性和新鲜感

**评估标准**：
- 是否是最新发生的事件
- 是否有"刚刚""今日""近日"等时间标识
- 是否有独家新闻价值
- 是否有第一手资料

**新闻性特征**：
✓ 突发事件
✓ 首次发布
✓ 最新数据
✓ 最新进展

**反面示例**：
❌ "某公司一直致力于XX"（无时效性）
✓ "某公司今日发布全球首款XX芯片"（有新鲜性）

---

#### 维度2：重要性（权重20%）

**定义**：内容对社会、行业、人群的影响程度

**评估标准**：
- 是否影响广泛人群
- 是否有重大政策影响
- 是否有行业变革意义
- 是否有历史性意义

**新闻性特征**：
✓ 影响千万人
✓ 改变行业格局
✓ 历史性突破
✓ 政策重大调整

**反面示例**：
❌ "某公司推出一款新产品"（重要性一般）
✓ "某公司推出全球首款XX芯片，将重塑芯片行业格局"（重要性高）

---

#### 维度3：接近性（权重15%）

**定义**：内容与受众的空间、心理距离

**评估标准**：
- 是否发生在受众所在地
- 是否与受众利益相关
- 是否与受众生活相关
- 是否与受众情感相关

**新闻性特征**：
✓ 本地事件
✓ 行业事件
✓ 生活相关
✓ 利益相关

**反面示例**：
❌ "某国外公司发布新产品"（接近性低）
✓ "某国内公司发布XX产品，将影响全国XX用户"（接近性高）

---

#### 维度4：相关性（权重15%）

**定义**：内容与受众认知、兴趣、需求的关联程度

**评估标准**：
- 是否符合受众兴趣
- 是否满足受众需求
- 是否解答受众疑问
- 是否引发受众思考

**新闻性特征**：
✓ 行业热点
✓ 社会热点
✓ 用户关注
✓ 需求满足

**反面示例**：
❌ "某公司发布一款小众产品"（相关性低）
✓ "某公司发布XX产品，解决XX用户长期痛点"（相关性高）

---

#### 维度5：异常性（权重15%）

**定义**：内容是否超出常规、预期，具有反常识性

**评估标准**：
- 是否超出常理
- 是否超出预期
- 是否有反常识性
- 是否有反直觉性

**新闻性特征**：
✓ 出人意料
✓ 反常识
✓ 首次突破
✓ 意外事件

**反面示例**：
❌ "某公司发布一款正常产品"（无异常性）
✓ "某公司发布全球首款XX芯片，性能提升10倍，震惊业界"（异常性高）

---

#### 维度6：冲突性（权重15%）

**定义**：内容是否包含矛盾、对立、争议

**评估标准**：
- 是否有矛盾对立
- 是否有争议话题
- 是否有冲突事件
- 是否有观点交锋

**新闻性特征**：
✓ 行业争议
✓ 观点对立
✓ 冲突事件
✓ 话题讨论

**反面示例**：
❌ "某公司发布产品，各方一致好评"（无冲突性）
✓ "某公司发布XX产品，引发行业热议，观点不一"（冲突性高）

## 二、网感评分体系（专项评分）

### 网感评分计算

**总分 = 100分**

**维度得分**：
- 新闻性（新鲜性）：20分
- 重要性：20分
- 接近性：15分
- 相关性：15分
- 异常性：15分
- 冲突性：15分

**扣分项**：
- 无时效性：-20分
- 导语不符合5W1H：-15分
- 导语超过80字：-10分
- 无数据支撑：-15分
- 引用不规范：-10分
- 客观性不足：-20分

### 网感等级

- **S级（90-100分）**：网感极佳，媒体录用潜力高
- **A级（80-89分）**：网感优秀，媒体录用潜力良好
- **B级（70-79分）**：网感良好，需优化
- **C级（60-69分）**：网感一般，需改进
- **D级（60分以下）**：网感差，必须重写

### 网感评分纳入9维度评估

在模拟用户评估的9维度中，新闻稿的"网感指数"基于上述6维度评分：

**9. 网感指数（1-5分）**
- 5分：网感极佳（S级）
- 4分：网感优秀（A级）
- 3分：网感良好（B级）
- 2分：网感一般（C级）
- 1分：网感差（D级）

**决策规则**：
- 网感指数 < 4分：直接重写，不允许通过
- 网感指数 ≥ 4分：才进入后续评估流程

## 三、基础规范

### 3.1 新闻稿基本要素

**5W1H原则（强制执行）**：
- Who（谁）- 主体是谁
- What（什么）- 发生了什么
- When（何时）- 什么时候发生
- Where（何地）- 在哪里发生
- Why（为什么）- 为什么发生
- How（如何）- 如何发生

**必备要素**：
- 标题（简洁有力，包含核心信息，体现新闻性）
- 导语（首段概括核心事实，包含5W1H，50-80字）
- 正文（详细展开，层次清晰，有数据支撑）
- 结尾（总结或展望，符合新闻结尾规范）
- 来源（署名/机构）
- 日期（发布时间，必须有时效性）

### 3.2 时效性要求（严格执行）

- **即时新闻**：2小时内发布（必须体现"刚刚""今日"等时间词）
- **当日新闻**：当日内发布（必须体现"今日""近日"等时间词）
- **深度报道**：可延至1-3天（需注明事件发生时间）
- **特稿/评论**：时间弹性大，质量优先（需有新闻挂钩）

**时效性评分**：
- 即时新闻（2小时内）：+20分
- 当日新闻：+10分
- 深度报道（1-3天）：+5分
- 无时效性标识：-20分

### 3.3 字数规范（严格执行）

- **快讯**：200-500字
- **标准新闻稿**：800-1500字
- **深度报道**：2000-5000字
- **长篇特稿**：5000字以上

**字数评分**：
- 符合标准：不扣分
- 超过标准20%：-5分
- 超过标准50%：-10分
- 超过标准100%：-20分

## 四、结构要求

### 4.1 倒金字塔结构（经典新闻结构，强制执行）

```
第一层：导语（最重要信息，首段，50-80字）
├── 核心事实
├── 关键数据
├── 主要结论
└── 5W1H要素

第二层：支撑细节（正文主体）
├── 背景信息
├── 相关数据
├── 专家观点
└── 细节展开

第三层：补充信息（背景和展望）
├── 历史背景
├── 对比案例
├── 行业影响
└── 未来展望
```

### 4.2 导语写作规范（强制执行，重要性最高）

**功能**：一句话抓住读者，概括核心内容

**写作要点**：
- 置于首段
- 包含最关键信息
- 包含5W1H要素
- 字数控制在50-80字
- 避免使用专业术语
- 体现新闻性（新鲜性、重要性等）

**导语评分**：
- 符合5W1H：不扣分
- 缺少1-2个W/H：-5分
- 缺少3个以上W/H：-15分
- 超过80字：-10分
- 无新闻性：-20分

**示例**：

❌ **错误示例**（无5W1H，无新闻性）：
```
近日某公司发布了一款新产品，引起了广泛关注。
```

✓ **正确示例**（包含5W1H，有新闻性）：
```
某公司（Who）今日（When）发布全球首款AI芯片（What），运算速度提升10倍（How），将重塑芯片行业格局（Why），引发业界强烈关注。
```

**分析**：
- Who：某公司 ✓
- What：发布全球首款AI芯片 ✓
- When：今日 ✓
- How：运算速度提升10倍 ✓
- Why：将重塑芯片行业格局 ✓
- 新闻性：全球首款、提升10倍、重塑格局 ✓

### 4.3 正文结构

**段落原则**：
- 每段一个核心观点
- 段落长度控制在3-5句
- 段落间有逻辑过渡
- 必须有数据支撑

**层次安排**：
- 按重要性递减排列
- 优先呈现最新、最重要信息
- 背景信息后置

### 4.4 结尾写法

**类型1：总结式**
"此次发布标志着..."

**类型2：展望式**
"未来，该公司将持续..."

**类型3：引用式**
"正如专家所说：'...'"

**类型4：提问式**
"这究竟是机遇还是挑战？让我们拭目以待。"

## 三、语言风格

### 3.1 新闻稿语言特点

**客观性**：
- 多用第三人称
- 避免主观评价
- 事实陈述为主

**准确性**：
- 数据要精确
- 用词要准确
- 逻辑要严密

**简洁性**：
- 避免冗长句式
- 删除不必要的修饰词
- 一句话表达一个意思

**时效性**：
- 用"近日""昨日""今日"等时间词
- 体现新闻的时效特征

### 3.2 禁用表达

❌ "我们认为..."
❌ "我觉得..."
❌ "非常棒..."
❌ "太好了..."
❌ 感叹号过度使用
❌ 夸张修辞（除特稿外）

### 3.3 推荐表达

✓ "据该公司介绍..."
✓ "数据显示..."
✓ "专家指出..."
✓ "行业分析师认为..."
✓ "截至昨日..."

### 3.4 语法规范

- 使用主动语态（优先）
- 避免被动语态滥用
- 短句为主，长句为辅
- 避免复合长句

## 四、事实核查

### 4.1 核查清单

**信息源核实**：
- [ ] 数据来源是否权威
- [ ] 人物姓名是否准确
- [ ] 机构名称是否正确
- [ ] 时间日期是否准确
- [ ] 地点信息是否准确

**内容验证**：
- [ ] 事实是否可验证
- [ ] 数据是否一致
- [ ] 引用是否标注来源
- [ ] 专家身份是否确认

**法律风险**：
- [ ] 是否涉及敏感内容
- [ ] 是否侵犯他人权益
- [ ] 是否符合广告法规定
- [ ] 是否有误导性信息

### 4.2 引用规范

**直接引用**：
- 用引号标注
- 注明来源
- 确保准确性

**间接引用**：
- 用"据...""..."介绍
- 不用引号
- 保留原意

**匿名引用**：
- 避免使用"消息人士"
- 如必须使用，说明理由
- 尽量提供更多信源

## 五、发布平台特性

### 5.1 权威媒体（新华社、人民日报）

**风格特点**：
- 政治站位准确
- 语言庄重规范
- 权威性强
- 国际传播视角

**结构要求**：
- 严格遵循倒金字塔结构
- 导语概括核心
- 支撑材料翔实
- 结尾有力

**注意事项**：
- 严守政治底线
- 用词严谨规范
- 避免争议性表达
- 注重国际影响

### 5.2 财经媒体（财新、第一财经）

**风格特点**：
- 数据驱动
- 专业深度
- 趋势预判
- 逻辑严密

**结构要求**：
- 数据前置
- 分析深入
- 趋势判断
- 风险提示

**注意事项**：
- 数据必须准确
- 分析有依据
- 避免主观臆断
- 注重专业性

### 5.3 深度媒体（南方周末、谷雨非虚构）

**风格特点**：
- 文学性与新闻性结合
- 细节丰富
- 叙事性强
- 人文关怀

**结构要求**：
- 故事化叙事
- 人物立体
- 场景再现
- 情感共鸣

**注意事项**：
- 深入采访
- 细节真实
- 情感克制
- 避免煽情

### 5.4 微信公众号

**风格特点**：
- 更有温度
- 更有互动性
- 视觉化表达
- 易于分享

**结构要求**：
- 标题吸引人
- 开头抓人
- 排版美观
- 结尾引导互动

**注意事项**：
- 避免过于正式
- 适当使用表情符号
- 段落不宜过长
- 增加配图建议

## 六、质量标准

### 6.1 新闻稿评分维度

**维度1：新闻价值（20%）**
- 时效性：是否及时
- 重要性：是否影响广泛
- 接近性：是否与读者相关
- 趣味性：是否有吸引力

**维度2：结构完整性（20%）**
- 标题：是否准确吸引
- 导语：是否概括核心
- 正文：是否层次清晰
- 结尾：是否有力收尾

**维度3：内容质量（25%）**
- 事实准确：是否核查无误
- 信息全面：是否覆盖关键点
- 数据支撑：是否有数据
- 来源可靠：是否有权威来源

**维度4：语言表达（15%）**
- 客观准确：是否避免主观
- 简洁明了：是否无冗余
- 专业规范：是否符合媒体风格
- 无语病：是否语法正确

**维度5：传播效果（20%）**
- 可读性：是否易读
- 分享性：是否易传播
- 互动性：是否易互动
- 记忆点：是否有印象

### 6.2 优秀新闻稿标准

✓ **5W1H齐全**：信息完整
✓ **导语精彩**：一句话抓住核心
✓ **结构清晰**：层次分明
✓ **事实准确**：核查无误
✓ **语言专业**：符合媒体风格
✓ **有数据支撑**：增强说服力
✓ **有专家观点**：增加权威性
✓ **有案例支撑**：增强可读性
✓ **有未来展望**：提供价值
✓ **无语法错误**：专业规范

### 6.3 常见错误

❌ 标题过长或过于平淡
❌ 导语未概括核心信息
❌ 结构混乱，层次不清
❌ 事实未经核实
❌ 主观评价过多
❌ 用词不准确
❌ 语法错误
❌ 缺乏数据支撑
❌ 引用未注明来源
❌ 结尾无力
