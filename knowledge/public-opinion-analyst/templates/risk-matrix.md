# 风险推演矩阵

## 使用说明
本矩阵用于"步骤五：风险拓扑学"，帮助系统化推演不同时间节点的风险演化路径。

## 二、黑天鹅事件预警矩阵

### 关键人物突然爆料

#### 触发条件识别
- [ ] 内部高层掌握核心证据
- [ ] 与公司存在重大利益冲突（离职纠纷/股权纠纷/个人恩怨）
- [ ] 已被监管部门接触
- [ ] 与媒体或KOL有密切联系

#### 影响程度评估
| 影响维度 | 影响程度 | 具体描述 |
|---------|---------|---------|
| **舆论层面** | 毁灭性 | 事实被证实，舆论彻底反转，企业丧失话语权 |
| **监管层面** | 极高 | 监管加速介入，调查力度加大 |
| **资本层面** | 极高 | 投资者信心崩塌，股价暴跌 |
| **业务层面** | 极高 | 用户大规模流失，业务受重创 |
| **法律层面** | 高 | 可能面临法律追诉 |

#### 应对预案
- **预防措施**：建立内部风险预警机制，及时识别潜在爆料人
- **应急措施**：第一时间评估信息真实性，准备应对方案
- **沟通策略**：主动披露，抢占话语权

---

### 监管突然表态

#### 触发条件识别
- [ ] 事件触及监管红线（食品安全/数据安全/垄断行为等）
- [ ] 舆论压力巨大（热搜持续/媒体持续报道）
- [ ] 上级批示介入
- [ ] 行业性问题暴露

#### 影响程度评估
| 影响维度 | 影响程度 | 具体描述 |
|---------|---------|---------|
| **舆论层面** | 极高 | 监管表态会放大舆论，延长舆情生命周期 |
| **业务层面** | 高 | 整改要求可能导致业务调整，经营受限 |
| **资本层面** | 高 | 投资者信心受挫，股价下跌 |
| **行业层面** | 高 | 可能引发行业整顿 |

#### 应对预案
- **预防措施**：主动与监管沟通，提前汇报情况
- **应急措施**：积极配合监管，展现整改意愿
- **沟通策略**：主动披露监管沟通情况，展现合规态度

---

### 权威媒体介入

#### 触发条件识别
- [ ] 事件具有典型性（代表行业性问题）
- [ ] 符合当前舆论导向（如消费者权益保护/反垄断）
- [ ] 已有足够新闻价值（涉及知名企业/大量用户）
- [ ] 有可挖掘的深度（非简单事件报道）

#### 影响程度评估
| 影响维度 | 影响程度 | 具体描述 |
|---------|---------|---------|
| **舆论层面** | 极高 | 舆论规模急剧扩大，可能登上热搜 |
| **监管层面** | 高 | 监管关注度提升，介入可能性增加 |
| **国际层面** | 高 | 可能引发国际传播 |
| **品牌层面** | 高 | 品牌形象长期受损 |

#### 应对预案
- **预防措施**：与权威媒体建立良好关系，主动提供信息
- **应急措施**：第一时间与媒体沟通，提供事实材料
- **沟通策略**：争取平衡报道，避免单方面叙事

- [ ] 平台算法推荐放大（进入推荐流）

- **应急措施**：多平台同步应对，避免顾此失彼
- **沟通策略**：平台差异化沟通（微博快速回应，抖音情感化表达，知乎深度解释）

## 三、风险传导网络

### 传导路径图

```
[舆论危机]
    ↓ (KOL放大/媒体报道)
[监管介入] ← → [股价下跌]
    ↓               ↓
[整改压力]     [投资者信心下降]
    ↓               ↓
[业务影响] ← → [融资困难]
    ↓
[用户流失]
    ↓
[市场份额下降]
    ↓
[员工动摇]
```

### 关键传导节点分析

#### 节点1：舆论危机 → 监管介入
- **传导条件**：舆情热度持续、触及监管红线、上级批示
- **阻断策略**：主动与监管沟通、快速整改、降温舆情
- **阻断成功率**：中

#### 节点2：舆论危机 → 股价下跌
- **传导条件**：投资者关注、媒体放大、分析师下调评级
- **阻断策略**：主动披露信息、稳定投资者预期、增持回购
- **阻断成功率**：中

#### 节点3：监管介入 → 业务影响
- **传导条件**：监管要求整改、罚款、限制经营
- **阻断策略**：积极配合整改、争取宽大处理、调整业务模式
- **阻断成功率**：低

#### 节点4：业务影响 → 用户流失
- **传导条件**：产品质量下降、服务受影响、品牌形象受损
- **阻断策略**：保障核心服务、用户沟通、补偿措施
- **阻断成功率**：中

#### 节点5：用户流失 → 市场份额下降
- **传导条件**：竞品抢占市场、用户口碑恶化
- **阻断策略**：产品改进、营销活动、用户召回
- **阻断成功率**：低

## 五、使用建议

### 1. 动态更新
- 风险推演应根据最新信息动态更新
- 每个时间节点后重新评估

### 2. 概率评估方法
- 基于历史数据、相似案例、当前态势综合判断
- 避免过度乐观或悲观

### 3. 应对预案编号
- 每个风险场景对应具体的应对预案
- 预案应提前准备，定期演练

### 4. 不确定性声明
- 对于概率评估，必须声明置信度
- 对于低置信度判断，需标注信息缺口
